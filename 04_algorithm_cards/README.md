# 算法卡

这里是算法 01～10 的正式交付区。

## 目录边界

| 目录 / 文件 | 用途 |
|---|---|
| `developer_version/` | 给数据开发落地的算法卡，必须说明输入表、字段、过滤逻辑、计算步骤、输出表和验收规则 |
| `business_readable/` | 给业务、产品和开发评审人员理解算法目的、业务流程和结果含义 |
| `算法文档输出规范.md` | 后续整理、修改和复核算法卡时必须遵守的格式和质量闸 |

业务原文承接矩阵、审阅清单和业务待确认汇总已经归档到 `archive/business_confirmations/`。这些材料只做溯源和内部复核，不作为开发主入口。

## 开发阅读顺序

```text
1. 先看 00_start_here/03_算法与结果表总览.md，确认 10 个算法的上下游和结果表。
2. 再看本目录 developer_version/ 中的具体算法卡。
3. 涉及字段、主键、状态、Doris 表和规则表时，以 03_data_contracts/ 为准。
4. 如需理解业务语义，再补看 business_readable/。
```

## V1 新品推荐品类范围

V1 新品推荐算法计算范围只覆盖 6 个大类：蔬菜、水果、肉禽蛋、冷藏加工、预制菜、水产。

基础数据仍按全量获取，不按品类裁剪。猪肉类在商品基础表中是独立大类，V1 不进入新品推荐算法计算和最终推荐结果。

各算法卡不逐张重复本口径；开发实现时在推荐候选、价格带、门禁和最终推荐结果环节统一按上述品类范围过滤。
