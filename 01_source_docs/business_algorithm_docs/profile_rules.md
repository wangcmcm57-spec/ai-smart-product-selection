# primary_profile V4 定义说明

## 设计原则

`primary_profile` 是会员的唯一一级消费者画像。V4 删除了“日常补货”和“待激活”这两个偏场景/运营动作的标签，只保留更稳定的人群行为定义：

- 消费频次：高频 / 中频 / 低频
- 家庭规模：大家庭 / 小家庭
- 特殊行为：捡漏型 / 价格敏感 / 上班族即时消费 / 常规消费

最终优先级：

1. 捡漏型消费
2. 上班族即时消费
3. 价格敏感
4. 常规消费

## 基础字段

- 月均小票数 = 会员小票数 / 活跃月份数
- 客单价 = 会员总消费金额 / 会员小票数
- 20点后消费金额占比 = 20点后消费金额 / 总消费金额
- 19点前折扣金额占比 = 19点前折扣金额 / 19点前折前金额
- 18-19点小票占比 = 18-19点小票数 / 总小票数
- 有蔬菜小票的19点前蔬菜SKU数 = 会员19点前买过蔬菜的小票中，平均每张小票购买的蔬菜SKU数

## 基础阈值

- 高频：月均小票数 >= 8
- 中频：2 < 月均小票数 < 8
- 低频：月均小票数 <= 2
- 大家庭：有蔬菜小票的19点前蔬菜SKU数 >= 3
- 小家庭：有蔬菜小票的19点前蔬菜SKU数 < 3
- 捡漏型：20点后消费金额占比 >= 64.31%
- 价格敏感：非捡漏，且19点前折扣金额占比 >= 14.10%
- 上班族即时消费：非捡漏，18-19点小票占比 >= 66.67%，且18-19点小票数 >= 2

## 关于“日常补货”

V4 不把“日常补货”作为 `primary_profile`。原因是补货更像一次购物任务，而不是稳定人群身份。同一个会员可能某次是补货，另一次是家庭餐桌采购，所以它更适合作为后续购物篮/小票层面的辅助场景，而不是会员唯一画像。
