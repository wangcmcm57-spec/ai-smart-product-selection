# AI 智能选品项目

本仓库用于沉淀 AI 新品推荐项目中可以协作、评审和开发落地的确定性材料。

当前 V1 目标是：围绕采购新品推荐场景，基于 Doris 基础数据、业务算法规则、外部竞品数据和机会评分逻辑，形成可被采购使用的 AI 选品能力。

## 仓库边界

放入 Git 的内容：

- 项目计划、待办、业务确认材料
- 业务原始算法规则的 Markdown 溯源材料
- 基础表、外部表、Doris 表的数据合同
- 给数据开发使用的算法卡
- 给业务和产品理解使用的业务解读版
- 架构图、时序图、运行流程图
- 可复用脚本
- 脱敏或人造样例数据

不放入 Git 的内容：

- 真实 Excel 业务导出
- 真实 CSV 明细或分析结果
- Doris 查询结果明细
- 久谦 API 原始返回数据
- PDF 原始资料
- 临时截图和运行输出
- Python 依赖包和缓存

## 目录说明

```text
00_project_management        项目计划、待办、业务确认材料
01_source_docs               业务原始与补充算法文档
02_data_contracts            基础表、外部表、Doris 表字段合同
03_algorithm_cards           算法卡开发版和业务解读版
04_product                   产品需求、业务流程、原型资料
05_architecture              架构图、时序图、运行设计
06_scripts                   可复用脚本
07_examples                  脱敏或人造样例数据
```

说明：真实业务数据、本地导出文件和临时验证结果可以放在本机 `local_only/` 目录，但该目录不进入 Git。

## 当前项目原则

1. 业务原始文档只做溯源，不直接改写。
2. 每个算法卡独立成文档，最终面向数据开发落地。
3. 算法卡需要同时具备业务可理解性和开发可执行性。
4. V1 暂不纳入供应商基础表、库存损耗明细表、促销优惠券明细表。
5. V1 聚焦新品推荐，不做毛利分析和购物篮提升产品能力。
