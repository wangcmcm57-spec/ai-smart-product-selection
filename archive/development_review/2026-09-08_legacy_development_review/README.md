## 建议开发顺序

```text
基础数据表、外部表、规则表整理
-> 有效交易过滤和公共维表关联
-> 算法 01 会员画像
-> 算法 02 门店品类等级
-> 算法 03 门店群消费者画像贡献
-> 算法 04 目标画像 SKU 表现
-> 算法 05 目标画像商品价格带
-> 算法 06 目标画像购物篮新品关联
-> 算法 07 竞品与全球外部趋势新品发现
-> 算法 08 新品候选标准化与合并
-> 算法 09 新品机会证据合成与风险门禁
-> 算法 10 新品推荐优先级与开发需求编排
-> 后端 API、Agent Harness、前端展示和反馈联调
```

说明：

```text
算法 05 的内部价格带可在算法 04 后先算。
算法 05 的竞对价格验证部分依赖算法 07 的可比竞对对象和竞品价格快照。
算法 08 正式读取算法 04/05/06/07 的候选和证据，再交给算法 09 和算法 10。
```
