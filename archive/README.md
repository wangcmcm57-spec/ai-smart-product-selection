# 历史归档

本目录只放历史材料、过程复核材料、旧原型、业务原文和已退出主阅读路径的评审资料。

归档材料可以用于溯源和复核，但不作为当前开发、联调或验收入口。当前开发入口统一从根目录 `README.md` 和 `00_start_here/` 开始。

## 当前归档内容

| 目录 | 内容 | 使用方式 |
|---|---|---|
| `business_confirmations/` | 业务待确认、审阅清单、业务原文承接矩阵和交付前复核记录 | 只在需要追溯算法口径或复核历史结论时查看 |
| `development_review/` | 已合并进导读层的旧开发链路、结果表总览和评审入口 | 历史参考，不作为当前开发入口 |
| `architecture/` | 已退出当前口径的历史架构图或说明图 | 历史参考，不作为当前架构入口 |
| `product/` | 旧版产品目录、过渡 PRD、旧原型和早期策略文档 | 历史参考，不作为当前需求基线 |
| `project_management/` | 旧项目管理 README 和 roadmap | 历史参考 |
| `source_docs/` | 业务原始 Markdown 文档和补充规则文档 | 只做溯源，禁止直接改写 |
