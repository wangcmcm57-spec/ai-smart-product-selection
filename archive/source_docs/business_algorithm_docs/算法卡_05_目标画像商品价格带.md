# 算法卡 05：目标画像商品价格带算法

文档状态：业务规则已确认  
适用范围：目标消费者价格接受、候选商品定价、成本谈判和竞对价格验证  
正式评估周期：最近 3 个数据完整自然月  
模型更新：每月正式更新；候选商品成本或竞对价格变化时重算可行性  
确认日期：2026-07-22

## 1. 算法澄清表

| 项目 | 业务问题 | 已确认规则 |
|---|---|---|
| 算法名称 | 这个算法叫什么 | 目标画像商品价格带算法 |
| 业务目标 | 解决什么问题 | 识别指定城市群、门店群、品类和消费者类型内部的可接受价格区间，并将候选商品的属性、全链路成本、目标毛利和竞对价格纳入可行性验证 |
| 算法边界 | 是否直接决定最终售价 | 输出价格带、建议价格点和成本上限；最终售价还需候选商品通过历史差销、当前货盘和风险过滤 |
| 计算对象 | 按谁计算 | 底层对算法 03 中全部有效消费者类型计算，产品默认展示正式主力人群 |
| 计算粒度 | 一条价格带代表什么 | 周期 + 城市/城市群 + 品类 + 门店群 + 消费者类型 + 可比商品组 + 规格段 + 标准计价单位 |
| 上游依赖 | 依赖哪些算法 | 算法 01 会员画像、算法 02 门店品类等级、算法 03 门店群消费者贡献、算法 04 目标画像 SKU 表现 |
| 使用数据 | 需要哪些数据 | 小票明细、商品基础表、促销和调价、实际到货、商品毛利、门店和日历、竞对商品和价格、供应商报价 |
| 数据周期 | 用多长时间 | 与算法 02—04 使用同一个最近 3 个完整自然月和同一正式版本 |
| 价格体系 | 输出几套价格 | 19:30 前非促销自然成交价格带、19:30 前商品促销价格带、19:30 及之后时段折扣接受价格带，三者分开计算 |
| 正式价格 | 小票用什么价格 | 商品成交价为主：原价-商品促销-时段折扣；分摊会员券后净实付价只作辅助 |
| 标准单位 | 不同规格怎么比 | 同时输出元/份和元/100g、元/kg、元/枚、元/件等可比标准单位 |
| 可比商品 | 哪些商品可以比价 | 同一小分类 + 主材料 + 商品形态 + 烹饪/加工方式 + 计量类型 + 相近规格段 |
| 规格段 | 如何生成 | 净含量取对数后使用 Jenks+BIC 动态选择 1—4 段，不使用人工固定区间 |
| 分布权重 | 小票、销量还是会员加权 | 同时输出会员平衡价格带和经营成交价格带；前者每名会员周期总权重为 1，后者按标准销售量加权 |
| 异常价格 | 超低价和极端价怎么办 | 先根据交易事实、促销和调价表分流；无法解释的统计异常需交叉核验后才排除，不简单截尾 |
| 价格带算法 | 自然价格带怎么分 | 加权 KDE 密度估计，带宽由交叉验证选择，峰值代表价格中心，自然谷值作为多价格带边界 |
| 需求验证 | 只看成交价够不够 | 不够；用 19:30 前非促销售罄率、实际到货暴露和经验贝叶斯收缩验证价格段是否有真实需求支撑 |
| 属性溢价 | 功能、口味、品牌和包装怎么定价 | 特征价格模型 + 分层收缩；只输出控制其他已知差异后的价格关联，不冒充因果效应 |
| 属性缺失 | 不知道包装怎么办 | 不用众数强行填补；无法拆分时只输出属性组合溢价，不将组合差异解释为单一属性溢价 |
| 到货和超卖 | 是否需要库存 | 不使用库存；净到货量=门店实际收货量，销售量/实际到货量>1.10 标记超卖异常并排除 |
| 目标毛利 | 毛利率怎么来 | 历史稳定可比商品全链路毛利率经收缩后做 KDE，健康群谷值为数据底线、密度峰值为数据目标；公司硬性毛利要求取更严值 |
| 成本交集 | 成本和价格带怎么结合 | 满足毛利的最低售价=全链路成本/(1-毛利率)，再与消费者价格带求交集 |
| 竞对价格 | 是否纳入竞争渠道 | 纳入外部验证层；竞对价格不与内部小票混算，无竞对销量时不得称为竞对消费者接受价格 |
| 19:30 后价格 | 是否进入价格带 | 包括 19:30 整点生效价格和成交，独立输出半小时折扣接受曲线，不与自然价格混算 |
| 样本不足 | 没有足够本地小票怎么办 | 使用分层贝叶斯借数，保留本地数据贡献比例和回退层级；更大区域只作先验，不直接替代本地结论 |
| 建议售价 | 输出区间还是单点 | 同时输出核心价格带、扩展价格带、具体建议零售价和成本谈判上限 |
| 稳定性 | 如何防止依赖某月或少数门店 | 删除月份、门店分块、会员分块重算，用密度重合度、价格带交并比和中心偏移验证 |
| 输出结果 | 最终输出什么 | 六张结果表，分别保存内部价格带、属性溢价、时段折扣、候选商品可行性、稳定性审计和竞对价格验证 |
| 验收方式 | 怎么判断合理 | 全量对账、公式复算、滚动回测、稳定性、竞对来源核验、边界场景和上线试点闭环 |

## 2. 算法定位与边界

### 2.1 本算法回答的问题

```text
在指定城市或城市群、门店群、品类和消费者类型下，
目标消费者的自然成交价格集中在哪里？
候选商品的属性、成本和目标毛利能否同时满足？
相似竞对商品的价格是否支持这个方案？
```

### 2.2 不回答的问题

```text
不单独决定应该开发什么商品
不用 19:30 后折扣价代替自然售价
不把竞对挂牌价当成竞对消费者真实接受价
不证明某个属性一定造成涨价
不跳过历史差销和当前货盘重复过滤
```

### 2.3 正确链路

```text
算法 01—04 正式结果
        +
目标画像小票、商品、促销、调价和实际到货
        ↓
内部自然/促销/时段折扣价格带
        +
商品属性溢价和 19:30 前需求支撑
        +
全链路成本与目标毛利
        +
竞品趋势算法输出的可比竞对价格
        ↓
算法 05：价格可行区间、建议价格点、成本上限和竞对价格验证
        ↓
历史差销、当前货盘和风险算法硬过滤
        ↓
供应商询价、打样和门店试点
```

## 6. 前置过滤与对账

### 6.1 有效会员和交易

会员过滤完全复用算法 01、03、04：

```text
customer_id 非空且不以“6”开头
只保留正常完成的正向销售
销售数量 > 0、成交金额 > 0
剔除退货、取消、冲销、测试和赠品/零金额行
剔除算法 01 已标记的异常会员日
```

目标画像价格带只使用目标 `final_profile` 的有效会员成交。全门店销售可作经营对账，不得混入目标会员价格分布。

### 6.2 商品映射和单位

```text
商品编码必须在交易日唯一命中正式商品记录
必须成功映射到目标品类
必须能转换到可比标准计价单位
```

映射冲突输出 `PRODUCT_MASTER_CONFLICT`，单位无法转换输出 `UNIT_CONVERSION_ERROR`，均不进入正式价格带。

### 6.3 实际到货和超卖

```text
净到货量 = 门店实际收货量

净到货量 <= 0
-> 不保留该门店 SKU 日

全日标准销售量 / 实际到货标准量 > 1.10
-> OVERSELL_ABNORMAL
-> 禁止将比率截断为 100%
-> 该门店 SKU 日不进入正式价格带和需求验证
```

本算法不使用库存或剩余库存口径。

### 6.4 全量分流对账

每条有效目标画像商品行必须唯一进入：

```text
自然价格流
促销价格流
19:30 及之后时段折扣流
或有明确原因的异常/排除流
```

禁止一条记录同时进入自然和促销价格带。

## 7. 价格口径与标准计价单位

### 7.1 主价格和辅助价格

```text
商品成交价
= 原价 - 商品促销优惠 - 时段折扣优惠

会员净实付价
= 商品成交价 - 可靠分摊到商品行的整单/会员券
```

主模型使用商品成交价。会员券只在底表已有可追溯商品行分摊时输出辅助价格；没有可靠分摊时不自行猜测。

### 7.2 标准价格

```text
standard_unit_price
= line_transaction_amt / standard_sales_qty
```

输出包括：

```text
元/份
元/100g
元/kg
元/枚
元/件
元/L 或元/100ml
```

称重、按件、体积和蛋类枚数不能跨 `measurement_type` 直接混合。

### 7.3 每份价和标准单位价同时保留

标准单位价用于比较，每份价用于采购定价和顾客感知。不得只输出“1.49 元/枚”而不告知“17.90 元/12 枚”。

## 8. 三套价格流与时间窗口

### 8.1 19:30 前非促销自然价格

```text
sale_time < 19:30:00
AND product_promotion_flag = 0
AND member_price_promotion_flag = 0
AND time_discount_flag = 0
```

这是新品自然定价的主要内部依据。

### 8.2 19:30 前商品促销价格

```text
sale_time < 19:30:00
AND 存在商品促销、会员促销或明确活动价
```

促销价格带用于识别促销接受和促销依赖，不代替自然价格带。

### 8.3 19:30 及之后时段折扣价格

```text
第一档：19:30:00 <= sale_time < 下一次调价生效时间
后续档：当次调价生效时间 <= sale_time < 下一次调价生效时间
```

19:30 整点生效的价格必须保留；19:30 整点成交进入第一档。最终以实际调价生效记录为准，不强行假设每天都严格每 30 分钟变价。

## 9. 可比商品组

### 9.1 一级强匹配条件

```text
同一小分类
+ 主材料
+ 商品形态
+ 烹饪/加工方式
+ 计量类型
+ 相近规格段
```

小分类是首要边界。不能因为商品名称相似，将不同小分类或不同商品形态混在一个价格带中。

### 9.2 溢价属性

```text
功能属性
口味
品牌
包装
保鲜时效
```

这些字段默认用于溢价分析，不作为所有商品的强制分组条件。当某属性会改变商品本质时，应在品类属性字典中将其升级为强匹配字段并做版本管理。

### 9.3 不能强行比较

```text
普通鸡蛋 != Omega-3 鸡蛋的属性溢价结论
带壳鲜蛋 != 液蛋
200g 即烹牛柳丝 != 200g 熟食牛肉
按枚蛋品 != 按 kg 散装蛋品
```

前者可以在同一基础可比组内用属性模型调整，后三类需要分开。

## 10. 规格段算法

### 10.1 净含量对数

```text
z_i = ln(net_content_i)
```

取对数用于降低大规格长尾对分组的影响。蛋类等按枚商品使用枚数，定量包装使用每份净含量。

### 10.2 Jenks+BIC 选择 1—4 段

在同一可比商品组内，对 `K=1..min(4, 有效不同规格数)` 运行加权 Jenks：

```text
SSE_K = SUM_i w_i * (z_i - mean_cluster(i))^2

n_eff = (SUM_i w_i)^2 / SUM_i(w_i^2)

BIC_K = n_eff * ln(SSE_K / n_eff) + K * ln(n_eff)
```

选择 BIC 最小的 K。权重使用有效交易暴露，不用 SKU 名称频次替代。

### 10.3 规格价格效应

即使已转换为标准单位价，大包装仍可能存在单位价折让，因此属性价格模型仍保留 `ln(net_content)`。

## 11. 两套价格分布权重

### 11.1 会员平衡价格带

设会员 `m` 在周期内有 `n_m` 次有效购买机会：

```text
w_member(m,t) = 1 / n_m

SUM_t w_member(m,t) = 1
```

同一小票同一商品的多行先合并为一次购买。该价格带回答“典型目标消费者接受什么价格”。

### 11.2 经营成交价格带

```text
w_operation(i) = standard_sales_qty_i
```

该价格带回答“门店实际销量主要实现在什么价格”。

### 11.3 使用优先级

```text
候选新品的内部接受价格
-> 优先使用会员平衡价格带

销量和毛利测算
-> 同时查看经营成交价格带
```

两者不得事后挑选更有利的一个来支持已有结论。

## 12. 异常价格和超低清货价

### 12.1 事实规则先于统计规则

```text
成交价 <= 0
单位无法转换
商品编码/价格规则无法唯一对应
超卖异常
```

上述记录直接进入异常流。

### 12.2 可解释低价不是异常

```text
19:30 及之后符合实际调价规则的低价
-> 进入时段折扣价格带

19:30 前有正式促销记录的低价
-> 进入促销价格带
```

超低清货价需保留，但不得拉低新品自然定价。

### 12.3 无法解释的统计异常

在同一可比商品组和规格段内，对 `ln(standard_unit_price)` 使用中位数/MAD 识别极端观测，但只先标记：

```text
STATISTICAL_PRICE_OUTLIER
```

然后交叉核验：

```text
商品基础表原价
促销表
调价表
小票行成交金额
商品规格和计量单位
```

仍无法解释时才从正式分布中排除，并保留原始记录、异常原因和复核链路。不对有效价格做简单 winsorize。

## 13. 加权 KDE 自然价格带

### 13.1 加权密度

对标准单位价 `p_i` 和对应权重 `w_i`：

```text
f_h(p)
= 1 / (h * SUM_i w_i)
  * SUM_i [w_i * K((p-p_i)/h)]
```

`K` 使用高斯核。会员平衡和经营成交分别计算一条密度曲线。

### 13.2 带宽自动选择

带宽 `h` 通过加权留一交叉验证选择：

```text
h_star = argmax_h SUM_i w_i * ln(f_{-i,h}(p_i))
```

不由业务人员输入“平滑程度”。

### 13.3 多峰分布

```text
密度峰值 -> 消费者集中成交的价格中心
相邻峰值间的密度谷值 -> 价格带自然边界
```

会员平衡概率质量最大的连续区间为主接受价格带，其他稳定峰为次接受价格带。

### 13.4 单峰分布

只有一个稳定峰值时，对每个可实现累计权重 `q` 求包含该峰值的最短连续区间 `I(q)`：

```text
W(q) = width(I(q))
```

在“覆盖权重增加”与“区间宽度扩张”曲线上选择最大曲率拐点，对应的 `I(q)` 为核心价格带。不固定使用 P25—P75。

### 13.5 离散和单一价格点

当有效价格点无法支撑连续 KDE 时，不强行平滑：

```text
所有有效成交价格完全相同
-> 核心和扩展价格带均为该单一价格点
-> distribution_status = SINGLE_PRICE_POINT

只有少量不同价格点
-> 保留加权离散价格分布
-> 不伪造连续峰谷
-> distribution_status = DISCRETE_PRICE_DISTRIBUTION
```

上述结果仍需通过到货暴露和 19:30 前需求支持验证。

### 13.6 扩展价格带

扩展价格带由主峰及与之连续的稳定次峰共同构成，用于评估价格边缘和谨慎试点，不与核心价格带等价。

## 14. 19:30 前需求支撑验证

### 14.1 价格段售罄率

只使用非促销 19:30 前有效 SKU 日：

```text
price_segment_pre1930_sell_through
= SUM(该价格段 19:30 前标准销售量)
  / SUM(对应门店 SKU 日实际到货标准量)
```

禁止先计算每个 SKU 日比率后简单平均。

### 14.2 低到货量收缩

按件或枚数计量时，使用 Beta-Binomial 经验贝叶斯：

```text
prior = Beta(alpha_group, beta_group)
posterior_mean
= (sold_before_1930 + alpha_group)
  / (actual_arrival + alpha_group + beta_group)
```

`alpha_group` 和 `beta_group` 由同城市群、同可比商品组历史数据最大似然估计，不是人工设置。

称重或体积类连续数据使用分层 Beta 回归，到货暴露量作为精度权重。到货越少，结果越向可比组稳定水平收缩。

### 14.3 暴露和置信度

同时输出：

```text
valid_store_cnt
valid_store_sku_day_cnt
actual_arrival_exposure
local_evidence_weight
sell_through_interval
```

“到货 1 件卖出 1 件”可以显示原始 100%，但不能直接识别为强需求。

### 14.4 价格段解释

```text
会员密度高 + 收缩后售罄率高
-> 真实需求支撑的核心价格段

会员密度高 + 收缩后售罄率低
-> 存在成交，但需求强度一般

原始售罄率高 + 到货暴露低
-> 证据不足
```

在核心价格带内，收缩后售罄率未明显下降的最高价格段可输出为 `exploratory_upper_price`，但不直接等于最终售价。

## 15. 特征价格与属性溢价

### 15.1 业务问题

本模块回答：

```text
在规格、城市、门店和时间等条件可比时，
某个功能、口味、品牌或包装属性
对应多少稳定价格差异？
```

不能用两个商品的简单均价差代替。

### 15.2 模型记录和变量

一条记录为：

```text
会员 ID + 小票 ID + 商品编码 + 成交日期
```

属性类别转换为与明确基准组比较的虚拟变量。例如：

```text
is_omega3 = 1：Omega-3 鸡蛋
is_omega3 = 0：普通鲜鸡蛋（基准组）
```

### 15.3 对数特征价格模型

```text
ln(standard_unit_price_i)
= alpha
+ beta_spec * ln(net_content_i)
+ SUM_a beta_a * attribute_{i,a}
+ city_effect
+ store_group_effect
+ week_effect
+ error_i
```

主材料、形态和加工方式已由可比商品组限定，仍存在可观测差异时可作控制项保留。

### 15.4 属性系数如何估计

两套权重分别估计：

```text
beta_hat = (X' W X)^(-1) X' W y
```

等价于最小化：

```text
SUM_i w_i * (observed_log_price_i - predicted_log_price_i)^2
```

属性系数不是业务手工填写的固定权重。

例如其他条件相同时：

```text
普通鸡蛋 = 1.20 元/枚
Omega-3 鸡蛋 = 1.40 元/枚

beta_omega3 = ln(1.40) - ln(1.20) = 0.1542
premium_omega3 = exp(0.1542)-1 = 16.67%
```

### 15.5 分层收缩

当属性在某城市群或可比组样本少时：

```text
beta_shrunk(g,a)
= lambda(g,a) * beta_raw(g,a)
  + (1-lambda(g,a)) * beta_parent(a)

lambda(g,a)
= tau_a^2 / (tau_a^2 + SE(g,a)^2)
```

`tau_a^2` 通过 REML/经验贝叶斯从各城市群历史数据估计。样本越稳定，`lambda` 越接近 1。

系数不确定性同时保留模型标准误和分块 Bootstrap 区间。分块单元至少要保留完整 SKU—门店—周价格结构，避免将同一 SKU 的重复小票误当成大量独立属性证据。正式输出 95% 区间：

```text
coefficient_interval_95
premium_interval_95
= [exp(beta_lower)-1, exp(beta_upper)-1]
```

### 15.6 单项和组合溢价

```text
单项溢价 = exp(beta_a)-1

属性组合溢价
= exp(SUM beta_a + 可识别的交互项)-1
```

多个百分比不得直接相加。交互项只在数据同时包含“单属性、组合属性和基准商品”并能识别时估计，不强行添加。

### 15.7 属性名称和建议商品必须一致

候选商品名称中的每个价值属性必须满足之一：

```text
有独立属性系数
有可识别的组合属性系数
或明确标记为未定价属性
```

例如只估计了 Omega-3 系数，就只能将价格结论表述为“Omega-3 鲜鸡蛋”。未估计“三天鲜”系数时，不得将结论改名为“三天鲜 Omega-3 鸡蛋”。

## 16. 属性缺失、共线性和可识别性

### 16.1 属性补充顺序

```text
商品基础表结构化字段
-> BOM/规格书
-> 商品标题和规格描述
-> 商品图片识别
-> 供应商商品资料
```

每个补充值保存：

```text
attribute_value
attribute_source
extraction_method
attribute_confidence
attribute_updated_at
```

### 16.2 不用众数强行填补

无法识别的属性保留 `UNKNOWN`。不得因为大部分商品使用纸盒，就将所有未知包装填成纸盒。

### 16.3 三模型敏感性验证

```text
模型 A：只使用属性已知记录，加入该属性
模型 B：使用全部记录，不加入该属性
模型 C：使用全部记录，UNKNOWN 作为独立类别
```

核心属性系数在三模型间变化明显时，降级为组合溢价或不可识别。

### 16.4 完全绑定

如果所有 Omega-3 鸡蛋都同时属于同一品牌和同一包装，数据无法拆分三者的独立效应。必须输出：

```text
Omega-3 + 品牌 + 包装组合溢价
```

禁止同时输出三个伪独立系数。

### 16.5 属性系数可使用条件

```text
属性在可比组内存在变化
设计矩阵可识别
置信区间和后验方向明确
删除月份和门店后方向不反转
会员平衡模型与经营成交模型不存在无法解释的方向冲突
```

该模型识别的是价格关联。如需证明增加属性导致消费者支付更高价格，需新品试点或价格实验。

## 17. 目标毛利率动态生成

### 17.1 全链路毛利率

对同城市群、同可比商品组和同门店群历史商品：

```text
sku_full_chain_margin_rate
= SUM(product_margin_amt) / SUM(product_sales_amt)
```

使用现有商品毛利额和销售额汇总，不对每日毛利率简单平均，不再重复扣减损耗。

### 17.2 小规模 SKU 收缩

```text
margin_shrunk_sku
= lambda_sku * margin_raw_sku
  + (1-lambda_sku) * margin_group
```

`lambda_sku` 由商品销售额和跨月波动自动估计。

### 17.3 毛利底线和目标

对收缩后毛利率做销售额加权 KDE：

```text
稳定正毛利健康群与低毛利群之间的自然谷值
-> data_margin_floor

稳定正毛利健康群的密度峰值
-> data_margin_target
```

如果公司配置财务硬要求：

```text
final_margin_floor
= max(data_margin_floor, company_margin_floor)

final_margin_target
= max(data_margin_target, company_margin_target)
```

公司毛利要求是经营硬约束，不是算法经验权重。

## 18. 全链路成本与价格带求交

### 18.1 全链路成本

```text
full_chain_cost
= supplier_quote_cost
+ packaging_cost
+ logistics_cost
+ processing_cost
+ other_attributable_cost
```

每个成本项必须保存来源和报价版本。

### 18.2 毛利可行售价

```text
minimum_floor_price
= full_chain_cost / (1-final_margin_floor)

minimum_target_price
= full_chain_cost / (1-final_margin_target)
```

### 18.3 与消费者价格带求交

```text
target_core_intersection
= [core_lower, core_upper]
  INTERSECT [minimum_target_price, +infinity)

floor_core_intersection
= [core_lower, core_upper]
  INTERSECT [minimum_floor_price, +infinity)
```

扩展价格带以相同方式计算。

### 18.4 反向成本上限

```text
cost_ceiling_at_price(P, G) = P * (1-G)
```

产品必须同时输出：

```text
核心价格上限对应的成本上限
建议零售价对应的目标毛利成本上限
当前成本与谈判上限差额
```

### 18.5 无交集

不得通过提高到消费者扩展价格上限以上来强行满足毛利。处理顺序：

```text
降低供应商报价
-> 调整规格
-> 调整包装或配方
-> 重新计算价格和属性
-> 仍无交集则不建议开发
```

## 19. 竞争渠道价格验证

### 19.1 职责边界

竞品趋势算法负责竞对数据采集、商品匹配、趋势和来源质量。算法 05 读取其标准化结果，进行价格可行性验证。

### 19.2 竞对可比条件

```text
同一小分类
+ 主材料
+ 商品形态
+ 加工/烹饪方式
+ 功能属性
+ 相近规格段
+ 标准计价单位
+ 同城市或相似城市群
+ 相近渠道类型
```

匹配结果分为：

```text
EXACT：同款
HIGHLY_SIMILAR：高度相似
CATEGORY_REFERENCE：仅同品类参考
NO_MATCH：无可比商品
```

`CATEGORY_REFERENCE` 不得进入正式竞对等价价格带。

### 19.3 竞对价格分流

```text
竞对日常标价
竞对会员价
竞对促销价
竞对时段折扣价
```

同一竞对 SKU、同一门店、同一天的重复快照只保留一条有效价格。日常价和促销价分开形成分布。

竞对缺少真实销量时，每个“竞对 SKU—门店—有效日”价格快照在同渠道层内等权，渠道间分开输出，不用采集次数冒充销量权重。

### 19.4 竞对等价价格

先换算为同一标准单位，再使用第 15 章中已验证的规格和属性系数校正差异。未验证属性不得用人工溢价校正。

### 19.5 竞对价格指数

```text
competitor_price_index
= our_recommended_standard_price
  / competitor_equivalent_price_center
```

输出我方低于、接近或高于竞对的价格位置。我方高于竞对时，必须有可识别属性溢价支撑；否则输出 `COMPETITOR_PRICE_RISK`。

### 19.6 竞对价格不能覆盖内部接受价

```text
竞对卖得更高
!= 我方目标消费者一定接受更高价格
```

竞对价格是外部验证层。内部核心价格带上限不因竞对高价而自动上调。

### 19.7 竞对图片和来源

产品端必须展示：

```text
真实竞对商品图片
商品名称
竞对渠道和城市
日常/会员/促销价
规格和标准单位价
采集日期
可点击来源链接
```

没有同款或高度相似品时输出 `NO_MATCH`，不用普通品类图片和价格冒充。产品端可另行展示候选商品 AI 概念图，但必须标记“AI 概念图”，不得标记为竞对图片或真实商品图。

## 20. 19:30 及之后折扣接受曲线

### 20.1 实际折扣率

```text
actual_discount_ratio
= stage_actual_unit_price
  / same_sku_day_pre1930_natural_unit_price
```

当日 19:30 前没有自然成交时，使用当日生效原价；两者都无法追溯时，该 SKU 日不计算折扣率。

### 20.2 每档指标

```text
stage_member_cnt
stage_ticket_cnt
stage_sales_qty
stage_sales_amt

stage_sales_to_arrival
= stage_sales_qty / actual_arrival_qty

cumulative_sell_through
= cumulative_sales_qty_to_stage / actual_arrival_qty
```

会员平衡权重和经营成交权重分别形成折扣率 KDE，输出目标消费者的折扣成交中心和深折扣依赖。

### 20.3 因果边界

如果各门店和日期使用完全相同的固定折扣节奏，时间和折扣深度无法分离。此时只能称为：

```text
时段折扣接受曲线
```

不得称为价格弹性或“降价导致销量增长”。只有存在可识别的跨门店、跨日期折扣差异时，才能用固定效应或准实验方法估计折扣影响。

## 21. 样本不足与分层借数

### 21.1 不使用固定人数门槛

不设置“少于 100 张小票就回退”。样本信息通过本地估计误差、价格波动和有效权重自动进入 `lambda`。

### 21.2 分布借数

```text
f_final(p)
= lambda_local * f_local(p)
  + (1-lambda_local) * f_parent_adjusted(p)
```

借数顺序：

```text
1. 当前城市群 + 当前画像 + 当前可比组 + 当前规格段
2. 当前城市群 + 当前画像 + 当前可比组，用净含量模型校正规格
3. 当前城市群 + 全部有效画像 + 当前可比组，保留画像偏移项
4. 当前城市群 + 当前小分类 + 相同主材料、形态和加工方式
5. 预先配置的相似城市群 + 当前可比组 + 当前规格段
6. 更大区域数据只作统计先验
```

### 21.3 回退不改变正式范围

结果仍属于当前城市群和目标画像，但必须显示：

```text
local_evidence_weight
parent_evidence_weight
borrowed_scope_type / borrowed_scope_id
result_evidence_type
```

所有内部层级都没有同类数据时，只能输出外部竞对和供应商参考，不冒充内部消费者成交结论。

## 22. 具体建议零售价

### 22.1 可行候选价格点

在以下集合内选择：

```text
消费者核心或允许试点的扩展价格带
INTERSECT
满足目标毛利或明确的毛利底线区间
INTERSECT
公司可执行价格阶梯
```

### 22.2 约束密度峰值

```text
P_star
= argmax_{P in feasible_price_points}
  member_balanced_density(P)
```

`P_star` 还必须位于需求支持未失效的价格段。存在多个价格密度峰时，先选会员密度更高者，再查看经营成交密度和 19:30 前需求支持。

### 22.3 价格阶梯

如果公司有 `9.9、12.9、17.9` 等可执行价格阶梯，在满足毛利的阶梯点中选择距离 `P_star` 最近者。不得为接近密度峰值而选择低于毛利底线的价格。

### 22.4 最终同时输出

```text
core_price_band
extended_price_band
recommended_retail_price
cost_negotiation_ceiling
consumer_price_upper_bound
competitor_price_index
```

建议零售价是当前数据和成本版本下的建议，不是永久固定价。

## 23. 稳定性验证

### 23.1 删除月份

三个月周期分别运行：

```text
删除第 1 个月，使用第 2—3 个月
删除第 2 个月，使用第 1、3 个月
删除第 3 个月，使用第 1—2 个月
```

### 23.2 门店和会员分块

```text
门店分块 Bootstrap：同一门店全部记录一起进出
会员分块 Bootstrap：同一会员全部记录一起进出
```

重复次数不固定为 500 次。按批增加重采样，直到价格带上下界和密度峰值的 Monte Carlo 误差连续两批小于系统可执行最小价格精度。

### 23.3 稳定性指标

```text
density_overlap
= integral min(f_full(p), f_resample(p)) dp

interval_jaccard
= intersection_length / union_length

normalized_center_shift
= abs(mode_resample-mode_full) / robust_price_scale_full
```

同时记录：

```text
建议售价是否仍在核心价格带
属性溢价方向是否反转
毛利可行状态是否变化
本地数据贡献是否变化
```

### 23.4 动态稳定等级

在同城市群全部价格带任务的稳定性指标上，使用 Jenks+BIC 动态划分：

```text
STABLE
NEEDS_ATTENTION
UNSTABLE
```

任一核心维度进入不稳定组时，整体不能标记为稳定。

## 27. 完整演示案例

以下为产研复算用模拟数据，不代表 Doris 生产实时结果。

### 27.1 案例 A：Omega-3 鲜鸡蛋 12 枚可进入开发

范围：

```text
2026 年 4—6 月
上海城市群
A 级门店群
蛋品-鲜鸡蛋
常规时段型-小家庭-中频-价格非敏感
候选商品：Omega-3 鲜鸡蛋 12 枚
```

可比商品组：

```text
鲜鸡蛋 + 带壳鲜蛋 + 未烹饪 + 按枚 + 10—12 枚规格段
```

有效数据：

```text
2,860 名目标会员
6,940 张小票
9 个可比 SKU
31 家门店
```

内部价格结果：

```text
会员平衡核心价格带：16.80—18.40 元/份
会员密度峰值：17.90 元/份
经营成交核心价格带：16.50—18.20 元/份
经营密度峰值：17.50 元/份
消费者扩展价格带：15.90—19.20 元/份
```

19:30 前需求验证：

| 价格段 | 目标会员覆盖 | 收缩后售罄率 |
|---|---:|---:|
| 16.50—17.40 元 | 31% | 78% |
| 17.50—18.40 元 | 45% | 75% |
| 18.50—19.20 元 | 14% | 52% |

属性模型：

```text
普通鲜鸡蛋 12 枚基准价格 = 15.95 元
Omega-3 属性系数 = 0.116
Omega-3 溢价 = exp(0.116)-1 = 12.3%

属性预测价格
= 15.95 * exp(0.116)
= 17.91 元
```

包装系数置信区间跨 0，不单独计入包装溢价。未估计“三天鲜”属性，因此商品名称不得写成“三天鲜 Omega-3 鸡蛋”。

毛利和成本：

```text
数据毛利底线 = 20.4%
数据毛利目标 = 24.1%
公司毛利底线 = 22%
公司毛利目标 = 25%

最终毛利底线 = 22%
最终目标毛利 = 25%

供应商报价 = 12.10 元
包装 = 0.35 元
物流 = 0.50 元
其他 = 0.15 元
全链路成本 = 13.10 元
```

```text
毛利底线最低售价 = 13.10 / 78% = 16.79 元
目标毛利最低售价 = 13.10 / 75% = 17.47 元

目标毛利与核心价格带交集
= 17.47—18.40 元
```

竞对验证：

| 竞对商品 | 12 枚等价日常价 | 12 枚等价促销价 | 匹配 |
|---|---:|---:|---|
| 竞对 A Omega-3 鸡蛋 12 枚 | 18.80 元 | 17.80 元 | 高度相似 |
| 竞对 B Omega-3 鸡蛋 10 枚 | 19.08 元 | 18.00 元 | 规格校正 |
| 竞对 C Omega-3 鸡蛋 12 枚 | 18.90 元 | 18.50 元 | 高度相似 |

```text
竞对日常价格中心 = 18.90 元
我方价格指数 = 17.90 / 18.90 = 94.7%
```

最终：

```text
建议零售价 = 17.90 元/12 枚
成本谈判上限 = 17.90 * 75% = 13.43 元
当前预计毛利率 = (17.90-13.10)/17.90 = 26.8%

数据证据状态 = LOCAL_OBSERVED
竞对验证状态 = COMPETITOR_VALIDATED
稳定性 = STABLE
开发动作 = READY_FOR_DEVELOPMENT
```

该价格结论仍需候选商品通过历史差销和当前货盘硬过滤。

### 27.2 案例 B：成本与价格带无交集

沿用案例 A 的消费者和竞对价格，但全链路成本变为 15.20 元：

```text
毛利底线最低售价
= 15.20 / 78%
= 19.49 元

目标毛利最低售价
= 15.20 / 75%
= 20.27 元
```

```text
19.49 元 > 消费者扩展价格上限 19.20 元
20.27 元 > 竞对日常价格上限 19.30 元
```

反向成本：

```text
在 19.20 元达到毛利底线的成本上限
= 19.20 * 78% = 14.98 元

在核心价格上限 18.40 元达到目标毛利的成本上限
= 18.40 * 75% = 13.80 元

在建议价 17.90 元达到目标毛利的成本上限
= 17.90 * 75% = 13.43 元
```

结果：

```text
价格毛利状态 = NO_FLOOR_INTERSECTION
开发动作 = REDESIGN_REQUIRED
进入核心价格带并达到目标毛利至少需降本 = 1.40 元
达到 17.90 元建议价需降本 = 1.77 元
```

重构供应商、规格、包装或配方后重算；仍无交集则 `NOT_RECOMMENDED`。

### 27.3 案例 C：本地证据少且属性不可拆分

范围：

```text
宁波城市群
A 级门店群
蛋品-鲜鸡蛋
上班族晚高峰型-小家庭-中频-价格非敏感
候选商品：低胆固醇鲜鸡蛋 10 枚
```

分层借数：

```text
本地数据贡献 lambda = 34%
上级参考贡献 = 66%
本地价格中心 = 16.20 元
上级校正后价格中心 = 16.80 元

收缩后中心
= 34% * 16.20 + 66% * 16.80
= 16.60 元
```

```text
核心价格带 = 15.90—16.90 元
扩展价格带 = 15.40—17.80 元
数据证据状态 = HIERARCHICAL_ESTIMATE
```

商品基础表缺少包装字段，且低胆固醇属性与特定品牌、纸浆包装完全绑定：

```text
可输出：低胆固醇 + 品牌 + 包装组合价格差异
不可输出：低胆固醇独立溢价、包装独立溢价
```

竞对和成本：

```text
竞对同类日常价格带 = 17.50—18.50 元
竞对促销价格带 = 16.80—17.90 元

全链路成本 = 12.90 元
毛利底线最低售价 = 12.90 / 78% = 16.54 元
目标毛利最低售价 = 12.90 / 75% = 17.20 元
```

17.20 元不在核心价格带，但在扩展价格带内并低于竞对日常价格。

```text
建议试点价格 = 17.20 元
数据证据状态 = HIERARCHICAL_ESTIMATE
竞对验证状态 = COMPETITOR_VALIDATED
开发动作 = CAUTIOUS_PILOT
属性状态 = BUNDLED_ATTRIBUTE_NOT_IDENTIFIABLE
```

如要在核心价格上限 16.90 元达到 25% 目标毛利：

```text
成本上限 = 16.90 * 75% = 12.68 元
需要降本 = 12.90 - 12.68 = 0.22 元
```

## 29. 不能做的事

```text
不能将自然、促销和 19:30 后折扣价混成一个价格带
不能遗漏 19:30 整点生效价格和成交
不能用固定 P25—P75 代替真实多峰价格分布
不能将超低清货价当成新品自然定价
不能把一件到货、一件售出的 100% 直接当成强需求
不能使用库存口径替代实际到货
不能将超卖比率截断为 100%
不能把两个商品的简单均价差全部解释为功能属性溢价
不能用众数强行填补未知包装或其他属性
不能在属性完全绑定时伪造独立属性系数
不能在商品名称中加入没有系数或未标记的价值属性
不能用更大区域价格直接替代城市群正式结果
不能在成本与扩展价格带无交集时强行推荐
不能因竞对售价更高就越过内部消费者价格上限
不能在竞对无销量时声称竞对消费者接受某价格
不能用普通品类竞对商品冒充同款或高度相似品
不能将 19:30 后折扣接受曲线直接解释为价格弹性
不能让价格算法跳过历史差销和当前货盘相似品硬过滤
```
