# 产品策略

本目录用于沉淀 AI 新品推荐工作台的产品定位、试点范围、目标用户和路线图。

这里回答：

```text
为什么要做；
先给谁用；
先解决哪个场景；
V1 做到什么程度；
V2/V3/V4 后续扩展什么；
哪些能力暂时不做。
```

建议文档：

```text
01_AI新品推荐产品定位.md
02_上海试点范围说明.md
03_目标用户与使用场景.md
04_V1_V2_V3路线图.md
```

不放算法公式、开发字段表、接口字段明细。

## 当前文档清单

| 文档 | 用途 |
|---|---|
| `01_AI新品推荐产品定位.md` | 说明项目背景、长期目标、V1 产品定位和核心价值 |
| `02_上海试点范围说明.md` | 固定上海试点的城市、用户、门店、分类和范围边界 |
| `03_目标用户与使用场景.md` | 说明华东采购用户、现有新品 SOP、AI 介入位置和使用场景 |
| `04_V1_V2_V3路线图.md` | 说明从推荐决策台到新品开发、供应商协同、上市复盘的阶段规划 |

## 当前策略口径

| 项目 | 当前口径 |
|---|---|
| 试点城市 | 上海 |
| 目标用户 | 华东采购 |
| 试点分类 | 蔬菜、水果、肉禽蛋、冷藏加工、预制菜、水产 |
| V1 产品形态 | AI 新品推荐决策台 / 新品雷达型工作台 |
| V1 核心输出 | 推荐方向、证据、风险、试点建议 |
| 长期目标 | 打通新品机会发现、采购判断、新品开发需求、供应商响应、试点上市和复盘闭环 |
