# B3 命名分类属性规则导入映射说明

来源文件：`B3-按竞对商品名称梳理的命名规则.xlsx`

目标表：

```text
dim_product_naming_rule
dim_special_product_required_attribute_rule
dim_competitor_category_mapping_rule
dim_candidate_attribute_dictionary
fact_rule_review_item
```

## 1. Sheet 处理总览

| Sheet | 是否导入标准表 | 目标表 | 处理说明 |
|---|---|---|---|
| `中类规则主表` | 是 | `dim_product_naming_rule` | 一行一个公司中类，沉淀命名结构、必填字段、查重字段和异常拦截 |
| `特殊物种必填规则` | 是 | `dim_special_product_required_attribute_rule` | 命中特殊物种或品类时，校验必填属性 |
| `竞对中类映射` | 是 | `dim_competitor_category_mapping_rule` | 外部菜品类型、商品类型映射到内部公司大类和中类 |
| `需复核样例` | 是 | `fact_rule_review_item` | 只作为人工复核入口，不直接决定算法结果 |
| `分类库参考` | 条件使用 | 品类编码映射辅助 | 优先使用 `dim_sku`，仅在缺少独立品类字典时作初始化参考 |
| `主数据字段参考` | 不直接导入规则表 | 规则设计参考 | 只用于判断哪些字段非空率较高，不作为算法正式输入 |
| `总览` | 不导入规则表 | 导入审计参考 | 可记录来源说明和样本规模，不进入算法 |

## 6. 属性字典初始化 `dim_candidate_attribute_dictionary`

对应表合同：[候选属性字典表](../dim_candidate_attribute_dictionary_候选属性字典表.md)

B3 不直接给完整属性字典，但可以生成 V1 初始字典候选。

初始化来源：

```text
中类规则主表：推荐名称结构、名称必填字段、关键可选字段、查重建议字段
特殊物种必填规则：物种/品类、必填字段、名称规则
需复核样例：识别物种/品名、规格、等级、果径、温层、处理形态
```

字段词到属性维度的初始映射：

| 字段词或表达 | 属性维度 | 处理规则 |
|---|---|---|
| 品名、品种、通用名、物种/品类 | `MAIN_PRODUCT` | 可自动生成，重点词需复核 |
| 主材料、原料、部位 | `MAIN_MATERIAL` | 可自动生成，肉类和水产重点复核 |
| 口味 | `FLAVOR` | 可自动生成 |
| 处理形态、加工方式 | `PROCESS` 或 `PRODUCT_FORM` | 无法区分时写 `REVIEW_REQUIRED` |
| 规格、净含量、件数 | `SPEC` | 可自动生成 |
| 销售单位、包装单位 | `SALES_UNIT` | 可自动生成 |
| 包装、袋装、盒装 | `PACKAGING` | 可自动生成 |
| 产地、原产国 | `ORIGIN` | 需结合合规证据，默认复核重点词 |
| 等级、果规、果径、个头大小 | `GRADE` 或 `SPEC` | 果径优先写 `SPEC`，等级写 `GRADE` |
| 有机、绿色、GAP | `CERTIFICATION` | 命中后必须联动合规词库 |
| 温层、状态 | `TEMPERATURE_STATE` | 可自动生成 |
| 存储条件 | `STORAGE_CONDITION` | 可自动生成 |
| 品牌 | `BRAND` | 可自动生成 |
| 型号 | `MODEL` | 生鲜 V1 谨慎使用，默认复核 |

属性字典字段生成：

| 来源 | 目标字段 | 转换规则 |
|---|---|---|

| 系统生成 | `canonical_attribute_code` | 对标准属性名和适用品类生成稳定编码 |
| 映射规则 | `attribute_dimension` | 按上方维度映射 |
| 系统识别 | `term_language` | 中文写 `zh`，英文写 `en`，混合写 `mixed` |
| 字段词或识别词 | `term_alias` | 原始词、别名或同义词 |
| 品类映射 | `applicable_category_code` | 从 `dim_sku` 或品类字典映射 |

## 7. 异常处理

| 场景 | 处理方式 |
|---|---|
| 中类编码和公司中类不一致 | `dim_product_naming_rule.rule_status` 写 `REVIEW_REQUIRED` |
| 覆盖小类为空 | 规则可导入，但需要记录为待补小类范围 |
| 必填字段为空 | 该中类命名规则不得写 `ACTIVE` |
| 特殊物种缺必填字段 | 特殊规则不得写 `ACTIVE` |
| 竞对映射到多个内部中类 | `mapping_status` 写 `REVIEW_REQUIRED` |
| 属性维度无法稳定判断 | 属性字典 `review_status` 写 `REVIEW_REQUIRED` |

## 8. 开发校验

```text
1. 中类规则主表导入后，同一 naming_rule_version + category_level2_code 只能有一条 is_active=1 的记录。
2. 特殊物种必填规则导入后，同一 special_rule_version + category_level2_name + product_keyword 只能有一条 is_active=1 的记录。
3. 竞对中类映射导入后，同一 mapping_rule_version + competitor_dish_type + competitor_product_type 只能有一条 is_active=1 的 ACTIVE 记录。
4. 需复核样例必须进入 fact_rule_review_item，不能直接进入正式规则表。
5. 属性字典中 REVIEW_REQUIRED 的词，不能直接进入正式候选名称。
```
