# 外部数据采集模块开发说明

## 1. 模块定位

本模块负责为算法 07 提供可追溯的外部数据输入。
它不是前端查询的一部分，也不是 Harness 的在线工具调用。

一句话：

```text
外部数据采集模块负责把外部商品、价格、规格、图片、文章、供需和风险线索采集成标准数据，再交给算法 07 离线计算。
```

## 2. 实现方式优先级

开发实现时按下面优先级选择，不建议把所有外部源都做成浏览器自动化。

| 优先级 | 实现方式 | 适用场景 | 说明 |
|---|---|---|---|
| 1 | 数据供应商 API | 久谦、授权商业数据源 | 最稳定，优先保存原始响应和接口参数 |
| 2 | 官方 API / RSS / 下载文件 | 官方价量、法规、行业公开数据 | 优先使用结构化或半结构化来源 |
| 3 | HTTP 采集服务 | 静态列表页、文章页、公开接口 | 可用 Python `requests` / `httpx` / `Scrapy` 等实现 |
| 4 | 无头浏览器采集 | 必须渲染后才能取得数据的页面 | 可用 Playwright 或同类方案，成本和稳定性要单独评估 |
| 5 | browser-harness | 页面结构验证、采集路径 PoC、人工辅助排查 | 不作为生产调度依赖 |

生产任务必须由可调度、可重试、可监控的采集服务承担。
browser-harness 可以帮助开发理解网页结构和验证抓取策略，但不能替代正式采集任务。

## 3. 标准采集链路

```text
配置外部数据源
-> 发起 API / HTTP / 浏览器采集
-> 保存原始响应、请求参数、采集时间和来源状态
-> 读取统一算法批次锁定的身份、单位、日期、范围和用途规则
-> 标准化商品、价格、规格、图片、文章和风险线索；价格和数量分别生成单指标证据
-> 分层检查技术质量、允许用途、商品身份和食品业务准入，保留逐字段问题
-> 锁定唯一观测及来源修订、原始/标准哈希和规则依据
-> 算法 07 按批次读取并生成外部证据和外部候选
```

任何外部证据都要能回答：

```text
来自哪里
什么时候采集
原始内容是什么
采集是否成功
是否允许展示图片或引用
如何映射到内部分类和候选属性
```

## 4. 当前已定义外部表

当前外部数据合同保留久谦链路的 3 张表，并补齐公开源链路：

| 表 | 一行代表什么 | 用途 |
|---|---|---|
| `ods_jiuqian_api_raw` | 一次久谦接口请求或采集批次 | 保存原始响应、接口参数、状态和错误 |
| `dim_competitor_sku` | 一个数据提供方 + 平台 + 城市 + 竞品 SKU | 保存竞品商品稳定属性 |
| `fact_competitor_sku_daily_snapshot` | 一个采集日期 + 平台 + 城市 + 竞品 SKU | 保存价格、销量、促销、售罄、评价和图片变化 |
| `ods_external_source_raw_snapshot` | 一次请求的一份完整原始响应 | 保存公开接口/文件/页面/文章及权威字典、单位/日期说明原文 |
| `dwd_external_evidence_normalized` | 一个 BATCH 内一条原始行的一种指标或文本事实 | 分开原始/标准值、单位、观测期/基期、身份、质量和用途 |
| `mart_external_evidence_quality_issue` | BATCH + 证据 + 字段 + 问题代码 | 保存多问题和 INFO，先按证据聚合再关联，禁止放大价量 |
| `mart_external_batch_input_manifest` | BATCH + run_id + 证据 | 保存本次选择/排除、原始/标准内容快照与哈希、规则/区域锁定及修正血缘 |
| `dim_external_evidence_interpretation_rule` | BATCH + 规则 ID | 参数合同位于 rule_tables/；保存权威身份、单位、日期、食品范围、用途、覆盖/时效和来源修订规则 |

上述表的完整字段、主键、状态、ETL 和验收分别见同名合同。新增来源复用这些标准合同并登记来源自己的粒度/字段映射/依据，不能只把抽取后的结论直接写进算法 07 结果表。合同已定义不证明生产已经按合同建表或通过真实数据验收。

## 5. 调度口径

| 任务 | 建议频率 | 产出 |
|---|---|---|
| 久谦数据采集 | 每日 | 原始批次、竞品 SKU、竞品每日快照 |
| 官方 / 行业 / 公开源采集 | 每日或按来源发布频率 | 原始快照、文章证据、价量和供需证据 |
| 图片可用性和授权校验 | 随采集或每日 | 图片状态、授权状态、异常原因 |
| 外部证据标准化 | 每日或每周 | 算法 07 可读取的标准外部证据 |
| 探索预警 | 每周 | 预览信号，不覆盖正式月度候选 |
| 正式候选冻结 | 每月 | 锁定 `external_data_cutoff` 后交给算法 07 正式运行 |

采购查询、前端页面和 Agent 对话不触发实时外部采集。

月度结果统一使用 `algorithm_batch_version = 'BATCH_' + DATE_FORMAT(calculation_end_date, 'yyyyMM')`，`calculation_end_date` 为本批次完整月月末。原始采集可以每日多次，`collection_batch_id` 不作为结果版本；实际运行只用 run_id 审计。公开标准证据、质量明细、输入清单和正式解释参数均以 BATCH 为主键组成部分。

首次运行按已登记规则自动锁定观测集合、修订选择、解释参数、原有属性/分类资产及区域快照。同批正常重跑读取原锁定清单，不直接取最新 SUCCESS；源修正沿用原 BATCH/规则/区域，仅替换有依据对应的观测，并记录新旧证据、原始快照、hash 和 rerun_reason。新规则/用途/门槛或区域变化默认下一完整月批次生效。

正式业务计算只读取本次完整成功发布的 SELECTED 集合。结果审计可读取该次 EXCLUDED/SUPERSEDED 记录，明确用于解释停止/隔离原因，不能进入价量、趋势、覆盖或候选计算。单表写入失败不切换整批读取；不合并所有成功采集或所有运行结果。业务确认一次规则/参数，系统按规则自动运行和发布；结果抽样复核不作为每次运行的批准按钮。

## 7. 异常处理

| 异常 | 处理方式 |
|---|---|
| 来源不可访问 | 记录采集失败，不用旧数据冒充新数据 |
| 字段缺失 | 写缺失状态，不能填 0 代替未知 |
| 页面结构变化 | 进入采集异常，不发布该来源新批次 |
| 授权状态未知 | 图片和引用默认不展示，只保留内部追溯 |
| 反复失败 | 标记来源不稳定，算法 07 只能读取已成功标准化批次 |
| 外部词无法映射内部分类 | 保留证据，不进入正式候选 |
| 官方商品代码缺品名/类别 | 技术侧取得权威字典并验证来源/市场/有效期；未匹配保持隔离，不按代码或相近名称猜补 |
| 已确证花卉 | 排除食品业务，原始快照及排除审计保留 |
| 类别未知 | 独立隔离，不和花卉一起删除 |
| 混合公斤/升表头 | 保留原文，绝对价格不比较；百分比作为独立指标，未确定商务趋势用途时不启用 |
| Yesterday/Last Week 无来源锚点 | 交易数据期 NULL，仅保留历史资料；修订日和采集日都不冒充交易日 |
| 来源 `-` 缺报 | 数值 NULL、SOURCE_NOT_REPORTED；不补 0，本轮不插值，缺报率另算 |
| 多问题或 INFO | 按证据＋字段＋问题代码保存；问题数、证据数和商品数分别统计，INFO 不计业务异常 |
| 来源多批次/修订 | 按输入锁定清单去重选取；不同内容无有依据修订规则时隔离，不自动取最后采集 |
| 用途/覆盖/延迟参数未登记 | 对应用途隔离，不自定阈值；其余有效来源继续，状态明确降级 |

## 8. 开发验收

开发交付本模块时，至少验收：

```text
同一采集批次可追溯原始响应
同一来源重复采集不会生成重复主键
采集失败有明确状态和错误原因
图片展示必须经过匹配和授权状态判断
每日快照能按日期、平台、城市和竞品 SKU 唯一
算法 07 能按外部数据截止时间读取稳定批次
浏览器自动化不是生产唯一依赖
原始快照、单指标证据、逐字段问题和选取清单可逐行追溯
百分比基期、数据期、发布时间、修订日和采集日彼此区分
单位/日期依据可定位且变换因子可复算
花卉排除与类别未知隔离分别对账
缺报NULL、真实0、合法负变化率和INFO样例均通过
质量问题先聚合后关联，价量/证据计数不放大
同观测SELECTED唯一，来源修订不重复累计
同批重跑复用原规则/区域/输入，源修正保留前后引用和hash
覆盖率分母独立可复核；未知分母/门槛写NULL，不假设满覆盖
单表失败不切换整批发布；生产尚未提交的验收项明确标记未验收
```

## 9. 和 browser-harness 的关系

browser-harness 可以用于：

```text
验证页面是否能打开
检查 DOM 和接口结构
辅助定位按钮、下载入口或分页逻辑
生成采集策略 PoC
排查采集失败原因
```

正式生产采集应沉淀为独立任务、脚本或服务，并接入调度、监控、重试、版本和审计。
不能要求算法 07 或 Harness 在采购查询时临时打开浏览器抓取数据。

## 算法07图片及能力修复口径（2026-10-16）

图片主要读取久谦product_image_url；其他外部源不单独找图/抓图，原响应已返回的链接按商品归属保留，无链接[]。对已有链接的独立匹配/授权校验与采集分别执行，未校验不展示；缺图不作为TECHNICAL错误，不删除可靠商品事实。V1不启用AI补图。

标准证据增加evidence_time_type与metric_role：统计数据期、零售观测、文章发布、静态属性分流；会员/日常/促销/划线价格独立，POS排名不等于销量。按修订后的标准证据与锁定清单合同处理，静态属性不强制有交易期。

来源覆盖/缺报/时效产mart_external_source_coverage_audit；应报集合独立于实际收到记录，未知分母/门槛NULL，不自动启用商务趋势或香港额外用途。07→05使用mart_external_candidate_price_input逐来源商品和价格角色交接，旧消费者未联调为BLOCKED。具体模型、文字无图路径、候选出口及有限终止均以07开发卡第17节为准。
