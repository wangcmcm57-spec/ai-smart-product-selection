# 04_product 产品需求文档中心

本目录用于维护 AI 智能选品项目的产品侧需求，当前重点服务“上海试点 AI 新品推荐工作台”。

## 当前目录结构

```text
04_product/
├── 01_requirement/
│   ├── 01_上海试点_AI新品推荐工作台_需求说明V1.md
│   └── 02_上海试点_AI新品推荐工作台_原型.html
├── 02_launch_feedback/
└── archive/
```

## 目录说明

| 目录 | 用途 |
|---|---|
| `01_requirement/` | 当前正式需求包，包含需求说明和页面原型 |
| `02_launch_feedback/` | 后续放上线验收、采购试用反馈和复盘记录 |
| `archive/` | 历史草稿、旧目录结构、过渡文档和废弃原型 |

## 当前正式文件

| 文件 | 用途 |
|---|---|
| `01_requirement/01_上海试点_AI新品推荐工作台_需求说明V1.md` | 给开发落地使用的完整需求说明 |
| `01_requirement/02_上海试点_AI新品推荐工作台_原型.html` | 页面原型 Demo |

## 当前产品基线

| 项目 | 当前口径 |
|---|---|
| 页面入口名称 | AI 新品推荐 |
| 试点城市 | 上海 |
| 目标用户 | 华东采购 |
| 业务场景 | 新品推荐 |
| 商品范围 | 蔬菜、水果、肉禽蛋、冷藏加工、预制菜、水产 |
| 门店范围 | 覆盖上海全部门店群 |
| 门店群筛选 | V1 不让采购按门店群筛选，只作为推荐适用范围或试点建议展示 |
| 导出 | V1 不做推荐列表导出 |
| 反馈 | 有帮助 / 没帮助 |
| AI 边界 | 只解释当前查询结果或当前选中推荐，不生成新推荐，不实时重算算法 |

## 文档边界

`04_product` 只维护产品需求、原型、上线验收和反馈复盘。

算法公式、字段合同、Doris 表结构和算法 01～10 的正式开发卡不放在这里，分别维护在：

```text
02_data_contracts/
03_algorithm_cards/
00_project_management/business_confirmations/
```

## 维护规则

```text
1. 当前开发依据优先看 01_requirement/。
2. 新增需求内容优先补充到 01_requirement/01_上海试点_AI新品推荐工作台_需求说明V1.md。
3. 不再为前端、API、Harness、埋点单独新增顶级目录；需要展开时，作为主需求文档章节或同目录附件处理。
4. 上线验收、试用反馈和复盘记录放入 02_launch_feedback/。
5. 旧版草稿、过渡目录和废弃原型统一放入 archive/，不作为当前开发依据。
```
