# 业务 PRD

本目录用于放业务级产品需求，面向产品、业务、采购、开发和测试共同评审。

这里回答：

```text
采购进入页面后要完成什么任务；
页面需要支持哪些业务操作；
推荐结果应该如何呈现给采购；
哪些范围属于 V1；
哪些能力不在 V1；
业务验收时看什么。
```

当前优先维护主 PRD：

```text
01_上海试点_AI新品推荐工作台_业务PRD_V1.md
```

如后续主 PRD 过长，再单独拆出范围边界、业务复核清单或评审记录。

业务 PRD 不写底层 Doris 表结构，不替代算法卡，不展开 API、Harness 和埋点字段明细。
