# 上海试点范围说明

更新时间：2026-09-08

文档状态：第一版草案，待产品、业务和数据侧复核。

## 1. 文档定位

本文用于固定 AI 新品推荐工作台 V1 的上海试点范围，供业务 PRD、前端需求、API 需求、Harness 需求、埋点和验收文档引用。

本文只记录产品范围口径。算法卡和数据合同中的对应范围调整在算法侧文档另行处理。

## 2. 范围总览

| 范围项 | V1 口径 |
|---|---|
| 城市 | 上海 |
| 目标用户 | 华东采购 |
| 场景 | 新品推荐 |
| 门店范围 | 覆盖上海全部门店群 |
| 查询区域 | 运营大区，例如华东 1 区、华东 2 区、华东 3 区 |
| 商品大分类 | 蔬菜、水果、肉禽蛋、冷藏加工、预制菜、水产 |
| 不进入 V1 新品推荐范围 | 猪肉类 |
| 计划试用时间 | 2026 年 10 月中旬 |

## 3. 商品范围

最终确认 V1 试点为 6 个大分类：

| 序号 | 大分类名称 | V1 是否进入新品推荐 | 说明 |
|---:|---|---|---|
| 1 | 蔬菜 | 是 | 进入 V1 推荐范围 |
| 2 | 水果 | 是 | 进入 V1 推荐范围 |
| 3 | 肉禽蛋 | 是 | 进入 V1 推荐范围 |
| 4 | 冷藏加工 | 是 | 进入 V1 推荐范围 |
| 5 | 预制菜 | 是 | 进入 V1 推荐范围 |
| 6 | 水产 | 是 | 进入 V1 推荐范围 |
| - | 猪肉类 | 否 | 不进入 V1 新品推荐范围 |

前端筛选项、推荐列表、推荐详情、Harness 解释和试点验收均以这 6 个大分类为 V1 产品范围。

## 4. 猪肉类口径

猪肉类不进入 V1 新品推荐范围，含义是：

```text
前端大分类筛选项不展示猪肉类；
推荐列表不返回猪肉类新品推荐；
推荐详情不展示猪肉类新品推荐；
Harness 不围绕猪肉类生成 V1 新品推荐；
V1 成功指标不统计猪肉类新品推荐反馈和试点上架。
```

猪肉类仍可能在底层历史数据或画像模型中出现，含义不同：

```text
历史小票中仍可能有猪肉类消费；
商品基础资料中仍可能有猪肉类商品；
会员画像或家庭购物篮特征中仍可能使用猪肉类历史消费作为辅助特征；
毛利、价格、品类经营等历史分析中仍可能保留猪肉类。
```

因此，产品范围的限制不等于裁剪底层基础数据。

## 5. 数据和算法配合边界

产品侧要求是：

```text
V1 推荐展示结果只覆盖 6 个大分类；
V1 查询筛选项只开放 6 个大分类；
V1 采购看到的推荐和解释只围绕 6 个大分类；
V1 埋点和验收按 6 个大分类统计。
```

不在本文修改的内容：

```text
算法卡中的输入范围；
数据合同中的规则表字段；
Doris 明细表；
价格点规则、毛利规则、分类映射规则；
算法 05～10 的开发口径。
```

上述内容由算法侧文档单独调整和复核。

## 6. 门店和区域范围

V1 城市固定为上海，门店范围覆盖上海全部门店群。

“区域”指运营大区，不指上海行政区。页面可支持采购选择：

```text
全部运营大区；
华东 1 区；
华东 2 区；
华东 3 区；
后续业务确认的其他华东运营大区。
```

门店群不建议在 V1 作为采购必填筛选项。门店群更适合作为推荐结果中的适用范围展示，或作为后续高级筛选项。

## 7. V1 查询范围

采购查询条件：

| 查询条件 | V1 规则 |
|---|---|
| 运营大区 | 可选，默认全部 |
| 城市 | 固定上海 |
| 大分类 | 必选，只能选择 6 个大分类 |
| 中分类 | 必选，随大分类级联 |
| 小分类 | 可选，随中分类级联 |

查询结果只读取已生成的推荐结果，不在前端实时计算，也不让采购手动输入候选商品。

## 8. V1 不覆盖范围

```text
非上海城市；
多城市对比；
猪肉类新品推荐；
供应商报价协同；
采购向供应商发起新品开发需求；
新品审批流；
上市后自动复盘看板。
```

这些能力可以放入后续版本规划。
