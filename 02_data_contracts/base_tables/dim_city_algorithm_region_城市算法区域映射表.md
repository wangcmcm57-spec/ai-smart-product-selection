# 城市算法区域映射表

目标表建议名：`dim_city_algorithm_region`

表用途：提供城市到算法区域的映射口径，用于会员画像的主归属区域、区域熵权、Jenks 阈值和逻辑回归参数训练。

表粒度：一行 = 一个城市 + 一个算法区域映射生效周期。

主键：城市 + 生效开始日期。

关联要求：城市必须能和门店基础表里的城市字段对齐。

| 字段名 | 示例 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| 城市 | `上海` / `杭州` / `宁波` / `苏州` | 必须 | 门店基础表中的城市名称 |
| 算法区域编码 | `SH` / `NBHZ` / `SSCQ` | 必须 | 算法区域唯一编码，由业务确认 |
| 算法区域名称 | `上海` / `宁波杭州` / `苏锡常及其他` | 必须 | 算法训练和参数计算使用的区域口径 |
| 生效开始日期 | `2026-07-01` | 必须 | 该映射开始生效日期 |
| 生效结束日期 | 空 / `2026-12-31` | 建议 | 当前有效映射可以为空，历史映射需要回填结束日期 |
| 是否当前有效 | `1` / `0` | 必须 | `1` 表示当前有效，`0` 表示历史无效 |
| 映射确认人 | `张三` | 建议 | 业务确认人 |
| 映射确认日期 | `2026-07-20` | 建议 | 业务确认日期 |
| 数据更新时间 | `2026-07-20 10:00:00` | 必须 | 数据同步或维护时间 |
| 备注 | `嘉兴归入苏锡常及其他` | 建议 | 边界城市或临时调整说明 |
