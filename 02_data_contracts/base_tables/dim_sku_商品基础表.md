# 商品基础表

目标表建议名：`dim_sku`

表用途：提供商品维度基础信息，用于品类归属、规格换算、SPU 归并、商品属性分析和算法结果解释。

表粒度：一行一个商品 / 销售条码。

主键：交易商品编码。

关联要求：交易商品编码必须能和 Doris 小票商品明细表里的 `article_id` 对齐。

| 字段名 | 示例 | 说明 |
| --- | --- | --- |
| 交易商品编码 | `21231650` | 和 Doris 小票表 `article_id` 对齐 |
| 商品编码 | `21231650` | 商品主数据编码，如果和交易商品编码一致可重复保留 |
| 商品名称 | `牛肉丝250g` | 商品展示名称 |
| 大类编码 | `25` | 商品大类编码 |
| 大类名称 | `预制菜` | 商品大类 |
| 中类编码 | `2501` | 商品中类编码 |
| 中类名称 | `即烹类` | 商品中类 |
| 小类编码 | `250109` | 商品小类编码 |
| 小类名称 | `牛肉制品类` | 商品小类，门店品类等级核心字段 |
| SPU编码 | `30011883` | 商品归并用 |
| SPU名称 | `牛肉丝` | 商品归并用 |
| 规格 | `250g` / `1kg` / `称重` | 商品规格 |
| 单位 | `份` / `千克` | 销售单位 |
| 单位重量 | `0.25` | 单位 kg，用于规格换算 |
| 品牌 | `钱大妈` / `五湖` | 如果系统有则提供 |
| 产地 | `上海` / `山东` | 如果系统有则提供 |
| 存储条件 | `冷藏` / `冷冻` / `常温` | 损耗风险辅助 |
| 温层 | `冷藏` / `冷冻` / `热鲜` | 损耗风险辅助 |
| 保质天数 | `3` / `7` | 损耗风险辅助 |
| 是否标品 | `是` / `否` | 标品/生鲜区分 |
| 是否自加工商品 | `是` / `否` | 加工品识别 |
| 数据更新时间 | `2026-07-10 10:00:00` | 数据同步时间 |
