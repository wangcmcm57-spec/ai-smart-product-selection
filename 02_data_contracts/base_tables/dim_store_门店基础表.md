# 门店基础表

目标表建议名：`dim_store`

表用途：提供门店维度基础信息，用于城市、区域、门店状态筛选，以及所有门店粒度算法结果的关联。

表粒度：一行一个门店。

主键：门店编码。

关联要求：门店编码必须能和 Doris 小票商品明细表里的 `store_id` 对齐。

| 字段名 | 示例 | 说明 |
| --- | --- | --- |
| 门店编码 | `A1SH` / `501001` | 门店唯一编码，必须和小票表 `store_id` 对齐 |
| 门店名称 | `上海康桥宝邸` / `上海三湘四季` | 门店名称 |
| 城市 | `上海` | 门店所在城市 |
| 区域 | `粤西区` | 业务区域口径 |
| 管理区域 | `华东一区` | 业务管理区域 |
| 大区 | `华东区` | 上级大区 |
| 门店类型 | `直营` / `加盟` | 门店经营类型 |
| 开业日期 | `2019-04-13` | 门店开业日期 |
| 督导 | `薛俊龙` | 门店督导 |
| 主管 | `刘著捷` | 门店主管 |
| 门店状态 | `营业中` / `闭店` | 门店当前状态 |
| 是否营业 | `1` / `0` | `1` 表示营业，`0` 表示非营业 |
| 数据更新时间 | `2026-07-10 10:00:00` | 数据同步或更新时间 |
