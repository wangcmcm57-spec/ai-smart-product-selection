# 门店商品每日可订可售表

目标表建议名：`mart_store_sku_daily_sale_order_status`

表用途：提供门店商品每日可售、可订状态。V1 已由业务确认为必做表，用于判断商品在门店没有销量时，是消费者不买，还是商品本身不可售、不可订，避免算法误判。

表粒度：日期 + 门店编码 + 销售商品编码。

主键：日期 + 门店编码 + 销售商品编码。

关联要求：门店编码对齐小票表 `store_id`，销售商品编码对齐小票表 `article_id`，订购商品编码对齐订购 / 进货 / 验收口径。

| 中文字段名 | 是否必须 | 中文注释 |
| --- | --- | --- |
| 日期 | 必须 | 每日状态日期 |
| 门店编码 | 必须 | 对齐小票表 `store_id` |
| 销售商品编码 | 必须 | 对齐小票表 `article_id` |
| 订购商品编码 | 必须 | 对齐订购 / 进货 / 验收口径 |
| 是否可售 | 必须 | `1` 可售，`0` 不可售 |
| 是否可订 | 必须 | `1` 可订，`0` 不可订 |
| 数据更新时间 | 必须 | 数据追溯 |

开发反馈时需要说明：

1. 是否可售来自哪个系统或字段。
2. 是否可订来自哪个系统或字段。
3. 销售商品编码和订购商品编码是否一对一；如果不是，需要说明映射关系。
4. 历史数据可回溯周期。
