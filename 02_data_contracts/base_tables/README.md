# 基础数据表合同

这里存放 V1 AI 新品推荐需要开发准备的内部基础数据表。

这些表都需要并行准备。当前项目不是给门店做订购系统，但 **门店商品每日可订可售表已经由业务确认为 V1 必做表**，原因是算法需要判断某个商品在某门店没有销量，到底是消费者不买，还是本来不可售、不可订。

## V1 必做清单

| 表合同 | 目标表建议名 | 数据准备方 | 关键关联字段 |
| --- | --- | --- | --- |
| [门店基础表](dim_store_门店基础表.md) | `dim_store` | 数据开发 | 门店编码对齐小票表 `store_id` |
| [商品基础表](dim_sku_商品基础表.md) | `dim_sku` | 数据开发 | 交易商品编码对齐小票表 `article_id` |
| [毛利损耗表](mart_sku_margin_loss_毛利损耗表.md) | `mart_sku_margin_loss` | 数据开发 | 门店编码 + 交易商品编码 |
| [门店商品日价格表](mart_store_sku_daily_price_门店商品日价格表.md) | `mart_store_sku_daily_price` | 数据开发 | 门店编码 + 销售商品编码 |
| [城市算法区域映射表](dim_city_algorithm_region_城市算法区域映射表.md) | `dim_city_algorithm_region` | 业务确认 + 数据开发维护 | 城市 |
| [门店商品每日可订可售表](mart_store_sku_daily_sale_order_status_门店商品每日可订可售表.md) | `mart_store_sku_daily_sale_order_status` | 数据开发 | 日期 + 门店编码 + 销售商品编码 |

## 开发反馈要求

每张表请按以下口径反馈：

1. 字段是否能提供。
2. 字段来源系统或来源表。
3. 是否能按合同粒度产出。
4. 主键是否唯一。
5. 关联字段是否能和小票表对齐。
6. 数据更新频率。
7. 可提供的历史数据周期。
8. 缺失字段、替代字段和口径差异。

## 注意事项

- 小票商品明细表已有，不在这里重复建表，但所有基础表都要能和小票表关联。
- 交易商品编码必须能对齐小票表 `article_id`。
- 门店编码必须能对齐小票表 `store_id`。
- 真实 Excel、CSV、Doris 导出结果不放入 Git。
