# B1 公司毛利目标导入映射说明

来源文件：`B1—公司最低毛利率和目标毛利率是多少—2026年集团区毛利目标.xlsx`

来源 sheet：`各个区域毛利额-V2`

目标表：`dim_company_margin_target_config`

对应表合同：[公司毛利目标配置表](../dim_company_margin_target_config_公司毛利目标配置表.md)

## 1. 源文件结构

该 sheet 是多层表头的横表：

```text
第 2 行：指标分组，例如总销售额、销售额占比、供应链毛利率、出库额、供应链毛利额、备注要求
第 3 行：具体列名，例如区域、全品类、蔬菜类、水果类、全品类-下限、全品类-上限
第 4 行开始：区域数据
```

导入时不能只按第 3 行列名读取，因为有多个 `全品类`。必须结合列号和第 2 行指标分组。

## 2. 导入目标

把 Excel 的区域横表转成规则长表：

```text
一行 = 一个毛利配置版本 + 一个区域 + 一个品类 + 一个生效周期
```

例如 Excel 一行“华东区”会拆成：

```text
华东区 + 全品类
华东区 + 蔬菜类
华东区 + 水果类
华东区 + 猪肉类
华东区 + 水产类
华东区 + 肉禽蛋类
华东区 + 预制菜
华东区 + 冷藏及加工类
华东区 + 标品类
```

## 3. 字段映射

| Excel 位置或来源 | Excel 原始含义 | 目标字段 | 转换规则 |
|---|---|---|---|
| 系统生成 | 毛利配置版本 | `margin_config_version` | 生成 `MARGIN_2026_V1`；后续业务更新时递增版本 |
| 第 3 行 `区域` | 区域名称 | `scope_name` | 原样写入 |
| 第 3 行 `区域` | 适用范围类型 | `scope_type` | 全国类记录写 `NATIONAL`；区域类记录写 `REGION`；无法判断写 `REVIEW_REQUIRED` 并进入导入异常 |
| 区域映射表 | 适用范围编码 | `scope_id` | 优先从 `dim_city_algorithm_region` 或区域字典映射；无法唯一映射时为空并留痕 |
| 横转纵生成 | 品类层级 | `category_level` | 全品类写 `ALL`；蔬菜类、水果类等写 `CATEGORY_LEVEL1`，以 `dim_sku` 分类口径为准 |
| 横转纵生成 | 品类编码 | `category_code` | 全品类写 `ALL`；具体品类从 `dim_sku` 或品类字典映射 |
| 横转纵生成 | 品类名称 | `category_name` | 来自列名，例如全品类、蔬菜类、水果类 |
| 第 2 行 `总销售额` + 第 3 行 `全品类` | 总销售额 | `total_sales_amt` | 区域级总销售额，所有拆分出的品类行都可透传，便于审计 |
| 第 2 行 `销售额占比` + 对应品类列 | 销售额占比 | `sales_share_rate` | 全品类取全品类列；具体品类取对应品类列 |
| 第 2 行 `供应链毛利率` + 第 3 行 `全品类-下限` | 全品类毛利底线 | `company_margin_floor` | 仅用于 `category_name=全品类` 的行 |
| 第 2 行 `供应链毛利率` + 第 3 行 `全品类-上限` | 全品类目标毛利 | `company_margin_target` | 仅用于 `category_name=全品类` 的行 |
| 第 2 行 `供应链毛利率` + 具体品类列 | 具体品类毛利率 | `company_margin_target` | 用于对应具体品类行 |
| 第 2 行 `供应链毛利率` + 具体品类列 | 具体品类毛利底线 | `company_margin_floor` | 当前 Excel 没有具体品类下限列，V1 先与该品类目标毛利写同值；后续如业务提供品类下限，发新版本覆盖 |
| 第 2 行 `出库额` + 第 3 行 `全品类-下限` | 出库额 | `outbound_amt` | 当前 Excel 仅有区域级出库额列，按原值透传；若为空则为空 |
| 第 2 行 `供应链毛利额` + 对应品类列 | 供应链毛利额 | `supply_chain_margin_amt` | 全品类取全品类列；具体品类取对应品类列 |
| 第 2 行 `备注要求` | 备注要求 | `remark_requirement` | 原样写入 |
| 系统生成 | 生效开始日期 | `effective_start_date` | 无单独业务生效日期时，V1 使用 `2026-01-01` |
| 系统生成 | 生效结束日期 | `effective_end_date` | 当前有效版本为空 |
| 系统生成 | 是否当前有效 | `is_active` | 当前版本写 1 |
| 系统生成 | 来源文件 | `source_file` | 写来源 Excel 文件名 |
| 系统生成 | 来源 sheet | `source_sheet` | 写 `各个区域毛利额-V2` |
| 项目维护 | 配置确认人 | `confirmed_by` | 有确认人则写确认人；没有可为空 |
| 项目维护 | 配置确认日期 | `confirmed_date` | 有确认日期则写确认日期；没有可为空 |
| 系统生成 | 数据更新时间 | `updated_at` | 导入时间 |

## 4. 横表转长表规则

```text
for each 区域行:
  生成 1 条全品类配置
  生成 N 条具体品类配置
```

具体品类清单以 Excel 中供应链毛利率分组下的品类列为准：

```text
蔬菜类
水果类
猪肉类
水产类
肉禽蛋类
预制菜
冷藏及加工类
标品类
```

## 5. 异常处理

| 场景 | 处理方式 |
|---|---|
| 毛利率为空 | 该品类行不导入正式有效规则，进入导入异常清单 |
| 毛利率大于 1 或小于 0 | 阻断该行导入 |
| 区域名称为空 | 阻断该行导入 |
| 品类无法映射编码 | 可导入中文名称，但 `category_code` 为空，并记录待映射 |
| 同一区域同一品类重复 | 阻断导入，人工确认后再重跑 |

## 6. 开发校验

```text
1. 导入后同一 margin_config_version + scope_name + category_name 只能有一条 is_active=1 的记录。
2. company_margin_target 不能低于 company_margin_floor。
3. 全品类行必须同时有 company_margin_floor 和 company_margin_target。
4. 具体品类行必须有 company_margin_target。
5. Excel 的原始行数乘以品类拆分数量，应能和导入行数对上。
```
