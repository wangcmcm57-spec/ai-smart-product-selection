# 合规词库导入映射说明

来源文件：`生鲜与食品商品命名合规词库_2026-08-18.xlsx`

目标表：

```text
dim_naming_compliance_term_rule
dim_category_naming_compliance_rule
dim_regulation_reference
fact_rule_review_item
dim_candidate_attribute_dictionary
```

## 1. Sheet 处理总览

| Sheet | 是否导入标准表 | 目标表 | 处理说明 |
|---|---|---|---|
| `词汇明细` | 是 | `dim_naming_compliance_term_rule` | 禁用词、需审核词、风险等级、审核材料、放行条件 |
| `分类命名规则` | 是 | `dim_category_naming_compliance_rule` | 分类维度的命名结构、必须核对项和证照提示 |
| `法规依据` | 是 | `dim_regulation_reference` | 法源代码、法规标准、重点条款、官方来源 URL |
| `审核工作台` | 条件导入 | `fact_rule_review_item` | 有实际审核记录时导入复核辅助表；空模板不导入 |
| `总览` | 不导入规则表 | 导入审计参考 | 可作为版本说明，不进入算法 |

## 2. 词汇明细导入 `dim_naming_compliance_term_rule`

对应表合同：[命名合规词规则表](../dim_naming_compliance_term_rule_命名合规词规则表.md)

源文件结构：

```text
第 4 行：字段表头
第 5 行开始：规则数据
```

字段映射：

| Excel 原始列 | 目标字段 | 转换规则 |
|---|---|---|
| 系统生成 | `compliance_rule_version` | 生成 `COMPLIANCE_2026_0818` |
| 序号 | `source_term_no` | 原样写入 |
| 序号 + 商品分类 + 词根/表达 | `term_group_id` | 生成稳定 ID；同一词组同一分类下保持稳定 |
| 商品分类 | `applicable_category_name` | 原样写入；`通用（全部分类）` 表示全品类 |
| 管控结论 | `control_conclusion` | `禁用` 转 `BANNED`；`需审核` 转 `REVIEW_REQUIRED`；有条件放行类写 `ALLOW_WITH_CONDITION` |
| 风险等级 | `risk_level` | `红` 转 `HIGH`；`黄` 转 `MEDIUM`；`绿` 转 `LOW`；其他写 `REVIEW_REQUIRED` |
| 二级场景 | `secondary_scene` | 原样写入 |
| 二级场景 | `risk_scene` | 可原样写入，后续需要时再做标准化 |
| 词根/表达 | `term_root` | 原样写入 |
| 常见变形或示例 | `common_variants` | 原样写入 |
| 规则属性 | `rule_attribute` | 原样写入 |
| 主要合规风险 | `risk_reason` | 原样写入 |
| 应审核材料 | `required_evidence` | 原样写入；禁用词可为空 |
| 放行条件/判定 | `release_condition` | 原样写入 |
| 建议规范表达 | `recommended_expression` | 原样写入 |
| 适用形态 | `applicable_form` | 原样写入 |
| 法源代码 | `law_reference_code` | 原样写入；多个代码保留原始分隔，算法使用时可拆分关联 |
| 生效口径 | `effective_scope` | 原样写入 |
| 系统生成 | `effective_basis` | 可写 `合规词库词汇明细` |
| 导入校验 | `rule_status` | 词根、管控结论、风险等级均有效写 `ACTIVE`；否则写 `REVIEW_REQUIRED` |
| 系统生成 | `effective_start_date` | 使用词库适用日期或导入确认日期 |
| 系统生成 | `effective_end_date` | 当前有效版本为空 |
| 系统生成 | `is_active` | 当前版本写 1 |
| 系统生成 | `source_file` | 写来源 Excel 文件名 |
| 系统生成 | `source_sheet` | 写 `词汇明细` |
| 系统生成 | `updated_at` | 导入时间 |

## 4. 法规依据导入 `dim_regulation_reference`

```text

字段映射：

| Excel 原始列 | 目标字段 | 转换规则 |
|---|---|---|

```

## 6. 联动属性字典

`词汇明细` 中的风险词、功能声称词、认证词，需要同步进入 `dim_candidate_attribute_dictionary`，方便算法 07/08 识别外部商品和候选名称。

字段映射：

| 来源 | 目标字段 | 转换规则 |
|---|---|---|
| 系统生成 | `attribute_dict_version` | 使用当前属性字典版本，例如 `ATTR_DICT_2026_V1` |
| 词根/表达 | `canonical_attribute_name` | 取词根中的标准表达 |
| 词根/表达 + 商品分类 | `canonical_attribute_code` | 生成稳定编码 |
| 二级场景/规则属性 | `attribute_dimension` | 功能声称写 `FUNCTION_CLAIM`；认证资格写 `CERTIFICATION`；禁用或高风险表达写 `RISK_CLAIM` |
| 常见变形或示例 | `term_alias` | 拆成别名记录；无法稳定拆分时保留原字符串 |
| 商品分类 | `applicable_category_name` | 原样写入 |
| 来源判断 | `rule_source` | 写 `COMPLIANCE_TERM` |
| 风险等级 | `confidence` | 合规词库命中可写 1 |
| 管控结论 | `review_status` | 禁用和需审核词均写 `REVIEW_REQUIRED`，由质量或法务复核放行条件 |
| 管控结论 | `allow_in_candidate_name` | 禁用词写 0；需审核词默认写 0，审核通过后可更新 |
| 管控结论 | `is_risk_term` | 写 1 |

## 7. 异常处理

| 场景 | 处理方式 |
|---|---|
| 词根为空 | 阻断该行导入 |
| 管控结论无法识别 | 导入为 `REVIEW_REQUIRED`，不得自动放行 |
| 风险等级无法识别 | 导入为 `REVIEW_REQUIRED` |
| 法源代码找不到法规依据 | 合规词规则可导入，但 `rule_status` 写 `REVIEW_REQUIRED` |
| 官方 URL 为空 | 不阻断导入，但法规依据表记录为空并进入审计提醒 |
| 审核工作台为空模板 | 不导入复核表 |

## 8. 开发校验

```text
1. 词汇明细导入后，所有 law_reference_code 必须能追溯到 dim_regulation_reference；多个代码要能拆分校验。
2. BANNED 规则命中后，算法 09 必须拒绝或退回，不得直接通过。
3. REVIEW_REQUIRED 或 ALLOW_WITH_CONDITION 必须有 required_evidence 或 release_condition。
4. 分类命名规则中的证照提示必须能传给算法 09 风险门禁。
5. 审核工作台只作为复核记录，不直接改写算法正式结果。
```
