# 竞品每日快照表

目标表建议名：`fact_competitor_sku_daily_snapshot`

表用途：保存竞品每天变化的数据，比如价格、会员价、销量、促销、覆盖门店数。后续竞品趋势、价格带、销量趋势都依赖这张表。

表粒度：采集日期 + 数据提供方 + 竞品平台 + 城市 + 竞品 SKU 编码。

主键建议：采集日期 + 数据提供方 + 竞品平台 + 城市 + 竞品 SKU 编码。

关联要求：

| 关联对象 | 关联字段 | 要求 |
| --- | --- | --- |
| 竞品 SKU 基础表 | 数据提供方 + 竞品平台 + 城市 + 竞品 SKU 编码 | 补商品名称、类目、规格、图片 |
| 久谦接口原始表 | 数据采集批次号 | 追溯原始接口 |
| 后续竞品趋势汇总表 | 采集日期 + 城市 + 类目 / 方向 | 作为趋势算法输入 |

字段清单：

| 字段名称 | 示例 | 说明 |
| --- | --- | --- |
| 采集日期 | `2026-06-13` | 竞品数据日期 |
| 数据提供方 | `久谦` | 数据供应方 |
| 竞品平台 | `叮咚买菜` | 竞品平台 |
| 城市 | `上海市` | 城市 |
| 竞品 SKU 编码 | `6965f778a2b04a002da5d45c` | 外部商品编码 |
| 竞品商品名称 | `黑椒牛肉意大利面240g/盒` | 冗余保留，方便查询 |
| 当前售价 | `9.90` | 当前售卖价格 |
| 划线价 | `12.90` | 原价 / 市场价 |
| 会员价 | `9.90` | 会员价，没有可为空 |
| 规格 | `240g/盒` | 当天采集到的规格 |
| 标准规格重量 | `240` | 克重，方便做 500g 价格换算 |
| 折扣标签 | `近30天低价` | 促销 / 折扣标签 |
| 限时特卖信息 | `今日特价` | 限时特卖信息 |
| 月销量 | `1200` | 月销量，接口没有可为空 |
| 总销量 | `5000` | API 有则接，没有可为空 |
| 日销量 | `80` | API 有则接，没有可为空 |
| 评论数 | `326` | API 有则接，没有可为空 |
| 好评率 | `96%` | API 有则接，没有可为空 |
| 是否售罄 | `否` | API 有则接 |
| 覆盖门店数 | `38` | 覆盖门店 / 点位数量 |
| 原始记录数 | `5` | 原始采集记录数，用于聚合校验 |
| 数据采集批次号 | `20260710_SH_BEEF_001` | 来源批次 |
| 数据更新时间 | `2026-07-10 02:05:00` | 入库更新时间 |

久谦 API 需要确认能否提供以下字段：

- 评论数
- 好评率
- 总销量
- 日销量
- 是否售罄
- 商品详情链接
- 标准规格重量

如果 API 提供，就第一版一起接；如果不提供，可以先为空，但开发需要反馈缺失原因。
