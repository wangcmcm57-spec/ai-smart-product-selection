# 竞品 SKU 基础表

目标表建议名：`dim_competitor_sku`

表用途：保存竞品商品相对稳定的基础属性，对应架构图里的外部竞品表主体。

表粒度：数据提供方 + 竞品平台 + 城市 + 竞品 SKU 编码。

主键建议：数据提供方 + 竞品平台 + 城市 + 竞品 SKU 编码。

关联要求：

| 关联对象 | 关联字段 | 要求 |
| --- | --- | --- |
| 久谦接口原始表 | 数据采集批次号 | 可追溯来源批次 |
| 竞品每日快照表 | 数据提供方 + 竞品平台 + 城市 + 竞品 SKU 编码 | 关联每日价格、销量、促销 |
| 后续内部竞品匹配表 | 竞品平台 + 城市 + 竞品 SKU 编码 | 后续用于匹配内部商品，不直接对齐小票表 |

字段清单：

| 字段名称 | 示例 | 说明 |
| --- | --- | --- |
| 数据提供方 | `久谦` | 数据供应方 |
| 竞品平台 | `叮咚买菜` / `盒马` | 竞品所属平台 |
| 城市 | `上海市` | 竞品数据城市 |
| 竞品 SKU 编码 | `6965f778a2b04a002da5d45c` | 外部平台商品唯一编码 |
| 竞品商品名称 | `黑椒牛肉意大利面240g/盒` | 竞品商品名称 |
| 商品描述 | `加热即食，黑椒口味` | 商品描述，接口没有可为空 |
| 一级类目 | `方便食品` | 外部一级类目 |
| 二级类目 | `中式早餐` | 外部二级类目 |
| 三级类目 | `牛肉快手菜` | 外部三级类目，没有可为空 |
| 品牌 | `圃美多` | 竞品品牌，没有可为空 |
| 规格 | `240g/盒` | 原始规格 |
| 标准规格重量 | `240` | 统一换算成克，无法解析可为空 |
| 存储方式 | `冷藏` | 冷藏 / 冷冻 / 常温 |
| 商品渠道 | `前置仓` / `门店` / `电商` | 接口有则保留 |
| 自定义标签 | `近30天低价` / `高蛋白` | 外部标签 |
| 商品图片链接 | `https://xxx.jpg` | 竞品图片 |
| 首次采集日期 | `2026-06-13` | 第一次采集到该 SKU 的日期 |
| 最近采集日期 | `2026-07-10` | 最近一次采集到该 SKU 的日期 |
| 数据采集批次号 | `20260710_SH_BEEF_001` | 来源批次 |
| 数据更新时间 | `2026-07-10 02:05:00` | 入库更新时间 |
