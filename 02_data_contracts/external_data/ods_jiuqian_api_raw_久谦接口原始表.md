# 久谦接口原始表

目标表建议名：`ods_jiuqian_api_raw`

表用途：保存久谦 API 每次返回的原始数据，方便追溯、排错、重跑。

表粒度：一次接口请求 / 一个采集批次。

主键建议：数据采集批次号 + 接口名称 + 请求城市 + 请求类目 + 请求时间。

关联要求：

| 关联对象 | 关联字段 | 要求 |
| --- | --- | --- |
| 竞品 SKU 基础表 | 数据采集批次号 | 用于追溯竞品基础数据来自哪次接口 |
| 竞品每日快照表 | 数据采集批次号 | 用于追溯价格、销量、促销快照来自哪次接口 |

字段清单：

| 字段名称 | 示例 | 说明 |
| --- | --- | --- |
| 数据采集批次号 | `20260710_SH_BEEF_001` | 每次接口采集生成唯一批次 |
| 数据提供方 | `久谦` | 外部数据供应方 |
| 接口名称 | `竞品商品列表接口` | 久谦具体接口名称 |
| 请求城市 | `上海市` | 本次请求城市 |
| 请求类目 | `牛肉` / `快手菜` | 本次请求类目或关键词 |
| 请求参数 | `城市=上海市，关键词=牛肉` | 保存接口请求条件 |
| 请求时间 | `2026-07-10 02:00:00` | 接口请求时间 |
| 返回状态 | `成功` | 成功 / 失败 |
| 返回记录数 | `105` | 本次接口返回商品数量 |
| 原始返回内容 | `JSON原文` | 原始接口返回内容 |
| 错误信息 | `超时` / 空 | 失败时记录原因 |
| 数据更新时间 | `2026-07-10 02:05:00` | 入库更新时间 |
