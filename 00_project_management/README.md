# 项目管理目录

本目录放项目推进、开发评审、业务确认和文档规范相关材料。

## 目录说明

| 文件 / 目录 | 给谁看 | 用途 |
|---|---|---|
| `README.md` | 全体 | 说明本目录怎么读，避免把归档文件当成当前版本 |
| `roadmap.md` | 产品 / 项目侧 | 项目阶段目标和 V1 范围 |
| `算法文档输出规范.md` | Codex / 项目侧 | 算法卡、业务解读版、承接矩阵和审阅清单的输出规范 |
| `development_review/` | 开发 / 产品 / 项目侧 | SDD 开发评审资料，包括当前开发链路、结果表总览和评审问题清单 |
| `business_confirmations/` | 业务 / 产品 / 项目侧 | 业务待确认事项、内部审阅清单、业务原文承接矩阵和交付核对 |

## 当前阅读原则

开发评审不要从本目录逐个文件翻起，统一从仓库根目录的开发评审入口开始：

```text
README_开发评审入口.md
```

业务确认优先看：

```text
00_project_management/business_confirmations/pending_items/
```

旧版计划、旧版待办或已失效核对记录不再保留为当前文件；如需追溯，直接查看 Git 历史。
