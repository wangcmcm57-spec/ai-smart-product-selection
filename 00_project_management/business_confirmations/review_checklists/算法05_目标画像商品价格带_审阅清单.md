## 4. 审阅重点

你复核 05 时只需要重点看这几件事：

```text
1. 业务解读版是否能读懂：价格带和候选可行性是两件事。
2. 候选成本从哪里进入算法是否讲清楚。
3. 三套价格流是否分清楚：自然价、促销价、19:30 后折扣价。
4. 商品属性缺失会影响什么，是否没有被写成已具备。
5. 开发版是否保留了业务原文公式：Jenks+BIC、KDE、需求支撑、属性溢价、毛利交集、竞对价格指数。
6. 开发版是否没有再粘贴业务原文全文。
```

## 5. 交付判断

当前算法 05 文档可以进入评审。已确认的候选成本估算、促销代理口径、可比商品组自动生成规则、商品属性来源、公司毛利和价格点规则不再作为待确认红线。

| 场景 | 可交付内容 |
|---|---|
| 无候选成本估算结果 | 可交付 `mart_target_profile_price_band`、属性溢价、折扣曲线、稳定性审计；候选可行性只能输出缺失状态 |
| 无正式促销/调价明细 | 已确认使用 `DISCOUNT_PROXY_V1` 作为 V1 正式分流口径，并保留代理标记 |
| 商品属性不完整 | 可按已有属性输出价格带；强匹配属性缺失时可比组需标记 `ATTRIBUTE_INCOMPLETE`，属性溢价不得伪造 |
| 公司毛利和价格点规则已确认 | 可叠加公司毛利底线、目标毛利和可执行价格点；正式建议价仍需等待 `dim_company_margin_target_config`、`dim_price_point_rule_config` 落表和试跑校验 |
| 竞对匹配未完成 | 可输出内部价格带和候选成本交集，竞对验证状态输出 `NO_COMPARABLE_COMPETITOR` 或 `SOURCE_MISSING` |
