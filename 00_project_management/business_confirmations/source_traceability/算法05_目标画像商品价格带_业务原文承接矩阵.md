## 3. 数据合同承接结论

| 数据事实 | 结论 |
|---|---|
| 小票销售量 | Doris 小票明细没有单独 `qty` 字段，`weight` 按数据合同统一映射为销售标准量 |
| 小票金额 | `usual_amt` 是商品行实付金额，进入 `line_transaction_amt` |
| 小票折扣 | `discount_amt` 是商品行优惠金额，可做代理促销判断；`hour_discount_amt` 不是商品行时段折扣金额，不能按行直接求和 |
| 毛利损耗 | `mart_sku_margin_loss` 已到营业日期 + 门店 + 交易商品编码，支持销售、19 点前销售、进货、毛利、折扣、时段折扣和损耗 |
| 价格表 | `mart_store_sku_daily_price` 已到日期 + 门店 + 销售商品编码 + 验收商品编码，支持售价、19 点前均价、19 点后售价和出库到店成本含税 |
| 可订可售 | `mart_store_sku_daily_sale_order_status` 已到日期 + 门店 + 销售商品编码，支持可售、可订判断 |
| 城市算法区域 | `dim_city_algorithm_region` 已定义城市到算法区域映射，算法 05 沿用，不自行扩区 |
| 外部竞品 | 竞品基础表和每日快照表已定义；竞对关系由算法 07 输出，05 在价格验证时联动读取竞品快照价格并做等价价格校正 |

## 4. 红线缺口

以下不是重复询问数据合同粒度，而是会影响算法 05 正式落地的业务或实现红线：

| 红线 | 影响 |
|---|---|
| 公司毛利和价格点配置落表 | 业务口径已确认，开发需按数据合同落 `dim_company_margin_target_config` 和 `dim_price_point_rule_config`；B1 只作为毛利配置来源追溯 |
| 竞对匹配结果和价格快照质量 | 影响竞对价格验证状态，但不能覆盖内部消费者接受价 |
| 高级统计实现方式 | Jenks+BIC、加权 KDE、经验贝叶斯、特征价格模型、分层收缩和重采样稳定性需要开发评审实现方案 |
