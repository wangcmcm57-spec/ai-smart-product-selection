更新时间：2026-08-03

---

## 1. 先说明这次修正了什么

上一版把业务原文中的“锚点识别算法”压缩成了普通 SKU 表现判断，这是不准确的。

本版已经恢复业务原文核心：

```text
四维指标
Jeffreys 统计证据
稳健标准化
两级 CRITIC 动态赋权
Jenks+BIC 动态锚点分组
正式锚点准入
当前锚点与历史锚点
门店稳定性
时间稳定性
SKU 表现明细、标准商品表现、锚点汇总、参数表
```

这份审阅清单只用于看“还有哪些数据落地点需要确认”。

## 3. 已确认的 V1 落地口径

| 事项 | 结论 | 文档标记 |

| 第一版没有促销活动表 | 使用 `discount_amt > 0` 做折扣代理 | `promotion_identify_method = DISCOUNT_PROXY_V1` |

## 4. 需要数据开发验收的红线

本节不是重新确认数据合同粒度。毛利损耗表、可订可售表和价格表的主键粒度已经明确；这里检查的是开发实际交付是否按合同稳定产出。

| 编号 | 确认项 | 为什么重要 | 不满足时怎么处理 |
|---|---|---|---|
| D1 | 抽样验收 Doris `weight` 在计件商品中的件数/份数/袋数/只数口径是否稳定，并确认商品基础表单位可解释 | 目标画像标准销售量、毛利、售罄率、折扣阶梯 | 单位无法解释时写 `measurement_mapping_status = UNKNOWN`；换算异常写 `UNIT_CONVERSION_ERROR`；核心指标不可算时写 `result_status = DATA_INCOMPLETE` |
| D2 | 毛利损耗表按数据合同在营业日期 + 门店编码 + 交易商品编码粒度稳定、唯一地提供销售额和全链路毛利额 | 成本反推 | 若全链路毛利无法稳定取数，用门店商品日价格表 `出库到店成本含税` 做备选，并写 `cost_source = ARRIVAL_COST_TAX_INCLUDED` |
| D3 | 毛利损耗表按数据合同稳定提供门店进货数量、门店进货重量、门店订购数量（订购单位）、门店订购数量（重量口径） | 售罄率、有效在售 SKU 日、订购覆盖 | 字段异常时 `result_status = SELL_THROUGH_DATA_ERROR` 或 `DATA_INCOMPLETE`，不得填 0 |
| D4 | 门店 SKU 可订可售表按数据合同在日期 + 门店编码 + 销售商品编码粒度主键唯一，并稳定提供是否可订、是否可售 | 当前在售、正式锚点 | 若正式交付未按合同实现，不能判断当前正式锚点 |
| D5 | Doris 有效交易过滤是否按 `order_status`、`is_return`、`refund_type`、`business_source` 等字段完成 | 有效交易口径 | 未清洗则算法任务内必须补过滤规则 |

## 6. 不能再问错的问题

下面这些不是“让业务给固定阈值”的问题。

| 错误问法 | 正确处理 |
|---|---|
| 把锚点判断简化成固定阈值问题 | 业务已经给了 CRITIC + Jenks/BIC + 正式锚点准入规则 |
| 锚点是不是表现好就算 | 不是，必须进入最高表现组且满足 7 条准入 |
| 订购率要不要进综合分 | 不进入，只做覆盖解释 |
| 价格是否进算法 04 综合分 | 不进入，由算法 05 处理 |
| 损耗是否要分摊到目标画像 | 不分摊，算法 04 不再二次扣损耗 |

## 7. 可抽取到开发评审会的问题

这一节不是把整份审阅清单交给开发，而是从审阅清单里抽出需要数据开发确认的技术点。开发评审不要只问“能不能建表”，要逐项确认：

```text
1. 是否能按比较组运行稳健标准化。
2. 是否能实现 Jeffreys 95% 下界。
3. 是否能实现两级 CRITIC。
4. 是否能实现 Jenks+BIC 动态分组。
5. 是否能做留一门店、留一月稳定性验证。
6. 是否能输出参数表，保证结果可复算。
7. 是否能追溯到小票、上游版本、商品、到货、毛利和可订可售快照。
```

## 8. 当前结论

算法 04 现在可以按新版业务解读版和新版开发版算法卡进入评审准备。

需求评审时，建议你只重点盯 3 件事：

```text
1. 抽样验收 weight 在计件商品中是否稳定表示购买件数/份数/袋数/只数，并确认商品基础表单位可解释。
2. 个别 weight 异常 SKU 按已接受的销售额占比分摊兜底打标。
3. 毛利损耗表、可订可售表、Doris 有效交易过滤是否按数据合同验收。
```

业务算法逻辑本身不用你重新逐字判断一遍，业务原文已经确认，我们要做的是保证开发版没有漏掉。
