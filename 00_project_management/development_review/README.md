# AI 选品 V1 开发评审资料

本目录存放 SDD 开发评审用的规格文件。开发不用逐页阅读业务原始文档，先按这里的入口理解本次评审范围、算法结果表和待确认问题。

## 文件说明

| 文件 | 用途 |
|---|---|
| `AI选品V1_当前开发链路.md` | 说明基础数据表整理、公共过滤逻辑、算法 01～10 当前状态、第一批开发范围和上下游依赖 |
| `算法01-06_结果表总览.md` | 汇总基础数据表、算法 01～06 的正式结果表、关键表和主要上游 |
| `AI选品V1_开发评审问题清单.md` | 记录评审会需要确认的问题、确认人和会后行动项 |
