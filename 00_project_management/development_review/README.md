# AI 选品 V1 开发评审资料

本目录存放 SDD 开发评审用的规格文件。开发不用逐页阅读业务原始文档，先按这里的资料理解完整 V1 链路、算法结果表和评审问题。

完整开发评审阅读顺序只维护在根目录：

```text
README_开发评审入口.md
```

本 README 只说明本目录里的 SDD 评审文件用途，不重复维护完整阅读顺序。

## 文件说明

| 文件 | 用途 |
|---|---|
| `quick_read/` | 给开发快速理解项目、链路和算法 01～10，不替代正式算法卡 |
| `AI选品V1_当前开发链路.md` | 说明基础数据表整理、公共过滤逻辑、算法 01～10 当前状态、分阶段实施建议和上下游依赖 |
| `算法01-10_结果表总览.md` | 汇总基础表、外部表、规则表和算法 01～10 的正式结果表、关键表和主要上游 |
| `AI选品V1_开发评审问题清单.md` | 记录评审会需要确认的问题、确认人和会后行动项 |

## 建议开发顺序

```text
基础数据表、外部表、规则表整理
-> 有效交易过滤和公共维表关联
-> 算法 01 会员画像
-> 算法 02 门店品类等级
-> 算法 03 门店群消费者画像贡献
-> 算法 04 目标画像 SKU 表现
-> 算法 05 目标画像商品价格带
-> 算法 06 目标画像购物篮新品关联
-> 算法 07 竞品与全球外部趋势新品发现
-> 算法 08 新品候选标准化与合并
-> 算法 09 新品机会证据合成与风险门禁
-> 算法 10 新品推荐优先级与开发需求编排
-> 后端 API、Agent Harness、前端展示和反馈联调
```

说明：

```text
算法 05 的内部价格带可在算法 04 后先算。
算法 05 的竞对价格验证部分依赖算法 07 的可比竞对对象和竞品价格快照。
算法 08 正式读取算法 04/05/06/07 的候选和证据，再交给算法 09 和算法 10。
```

基础数据表字段和粒度看：

```text
02_data_contracts/
```

算法字段、公式、状态和验收看：

```text
03_algorithm_cards/developer_version/
```
