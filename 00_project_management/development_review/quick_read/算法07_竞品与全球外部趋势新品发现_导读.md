# 算法07_竞品与全球外部趋势新品发现_导读

## 1. 一句话理解

算法 07 做的是：

```text
从竞品、公开趋势和外部市场信号里，找出可能值得参考的新品方向。
```

它回答的是“外面有没有类似机会，市场证据强不强”。

## 2. 它在链路里的位置

算法 07 是外部证据来源。

```text
内部机会来自 06
外部机会和验证来自 07
08 再把内外部候选统一标准化
```

它和 06 的区别是：06 看内部购物篮，07 看外部市场信号。

## 3. 它读什么

它读竞品商品、竞品价格、公开趋势、来源证据和必要的属性映射规则。
外部信号必须保留来源，不能只保留一句趋势描述。

采集实现边界看 `02_data_contracts/external_data/外部数据采集模块_开发说明.md`。
生产采集应由 API、HTTP 采集服务或必要的无头浏览器任务承担，`browser-harness` 只作为页面结构验证、采集 PoC 和问题排查工具。

## 4. 它做什么

算法 07 会把外部商品、趋势、价格和证据整理成可被后续读取的候选或验证信号。
如果外部证据只是趋势，不足以生成具体商品，要保留为趋势证据，不应硬写成商品名。

## 5. 它产什么

主要产出是外部候选、竞品证据、趋势证据和来源追溯结果。
这些结果进入算法 08，由 08 判断是否能和内部候选合并或形成标准候选。

## 6. 它不做什么

```text
不替代内部交易证据
不直接生成最终推荐
不直接做风险门禁
不把泛趋势强行写成具体商品
```

## 7. 下游谁用

算法 08 读取算法 07 的外部候选和证据。
算法 05 也可能读取其中的竞品价格验证信息，但正式候选进入推荐链路仍要经过 08。
