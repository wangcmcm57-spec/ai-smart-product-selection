# AI选品V1 快速导读包

这套文档给开发做快速理解，不替代 `02_data_contracts/`、`03_algorithm_cards/developer_version/` 和业务原文。

推荐阅读顺序：

1. [项目导读](AI选品V1_项目导读.md)
2. [链路图导读](AI选品V1_链路图导读.md)
3. [算法 01～10 导读总览](算法01-10_导读总览.md)
4. [算法单篇导读](#算法导读列表)

## 读法

先看项目导读，弄清楚这是什么项目、目标是什么、产出什么。
再看链路图导读，弄清楚离线、在线和反馈怎么连。
最后按算法 01 到 10 逐篇扫读，每篇只抓三件事：

```text
它读什么
它做什么
它交给谁
```
