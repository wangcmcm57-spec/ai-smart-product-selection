# 算法 01～10 结果表总览

本文给开发快速查看基础数据表、外部表、规则表和算法 01～10 要产出哪些表、谁依赖谁、哪些表是后端和 Agent 的主查询入口。

本文只做总览，不替代字段级合同。字段、主键、状态枚举和验收规则以 `02_data_contracts/` 和 `03_algorithm_cards/developer_version/` 为准。

## 1. 当前优先级

| 阶段 | 范围 | 处理方式 |
|---|---|---|
| P0 | 基础数据表、外部表、规则表、公共过滤逻辑 | 最先评审和建设，给全部算法提供稳定输入 |
| P1 | 算法 01、02、03 | 先产出画像、门店等级和画像贡献 |
| P2 | 算法 04、05、06 | 产出现有 SKU、价格带、候选价格可行性和购物篮内部候选 |
| P3 | 算法 07、算法 05 竞对价格验证 | 产出外部候选、竞品趋势、图片、风险线索和竞对价格验证 |
| P4 | 算法 08、09 | 产出标准候选、范围候选、机会证据和风险门禁 |
| P5 | 算法 10 | 产出推荐列表、详情摘要、解释、范围汇总和审计 |
| P6 | 后端 API / Agent / 前端 | 读取算法 10 表，不实时重算离线算法 |

## 5. 后端和 Agent 主查询表

| 场景 | 主读取表 | 说明 |
|---|---|---|
| 推荐列表 | `mart_new_product_recommendation_priority` + `new_product_recommendation_display_brief` | 默认列表入口，按区域、城市、品类、门店等级、画像等筛选 |
| 推荐详情 | `new_product_recommendation_display_brief` + `new_product_recommendation_explanation` | 展开推荐理由、证据、风险和试点建议 |
| 推荐解释追溯 | `new_product_recommendation_input_snapshot` + `new_product_recommendation_evidence_dimension` | 给 Agent 和详情页解释“为什么推荐” |
| 批次状态 | `new_product_recommendation_run` | 只读取最新成功批次，失败时按产品策略回退 |
