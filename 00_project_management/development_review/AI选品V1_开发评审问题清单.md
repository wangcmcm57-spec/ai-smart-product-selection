# AI 选品 V1 开发评审问题清单

本文用于开发评审会记录关键结论。评审不逐页朗读算法卡，只确认会影响开发启动、字段落地、调度依赖和验收方式的问题。

## 0. 文档定位

| 项目 | 内容 |
|---|---|
| 评审对象 | AI 选品 V1 第一批开发规格 |
| 本次重点 | 算法 01～03 和基础数据合同 |
| 预读范围 | 算法 04～06 只预读链路和依赖 |
| 更新中范围 | 算法 07～10 更新中，不进入本次开发细节评审 |
| 评审依据 | 开发版算法卡、数据合同、完整架构图、运行时序图 |
| 会议产出 | 基础表是否可开工、算法 01～03 是否可开工、字段口径结论、表建设计划、开发任务拆解 |

## 1. 评审结论要产出什么

评审结束后，需要明确：

1. 基础数据表整理是否可以进入开发。
2. 算法 01～03 是否可以进入开发。
3. 第一批要建哪些基础表、正式表和过程表。
4. 基础表字段、主键和数据周期是否满足。
5. 哪些口径由数据开发确认，哪些口径需要业务或财务确认。
6. 第一批开发任务怎么拆。

## 1.1 第一批开发执行顺序

第一批开发应按下面顺序拆任务：

1. 准备基础数据表和字段映射。
2. 落地有效交易过滤公共逻辑。
3. 开发算法 01 会员画像。
4. 开发算法 02 门店品类等级。
5. 开发算法 03 门店群消费者画像贡献。

对应文档：

- 基础数据表：`02_data_contracts/`
- 算法 01～03：`03_algorithm_cards/developer_version/`
- 结果表总览：`00_project_management/development_review/算法01-06_结果表总览.md`
