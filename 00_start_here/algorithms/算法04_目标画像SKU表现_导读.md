# 算法04_目标画像SKU表现_导读

## 1. 一句话理解

算法 04 做的是：

```text
找出目标画像下表现好的 SKU，作为后面新品判断的锚点。
```

它回答的是“什么货在这个人群和场景里表现好”。

## 2. 它在链路里的位置

算法 04 是从“人和场”进入“货”的第一步。

```text
01 画像
02 场景等级
03 人群贡献
-> 04 SKU 表现
```

它给 05、06 提供可以继续分析的商品锚点。

## 3. 它读什么

它读 01～03 的结果，再结合 SKU 销售、经营表现和相关基础数据，找出在目标画像里表现稳定或明显的商品。

## 4. 它做什么

算法 04 不是随机挑畅销品。
它要在目标画像和场景约束下，筛出真正能代表需求的 SKU，形成后续价格带和新品关联分析的锚点。

## 5. 它产什么

主要产出是 SKU 表现结果、锚点结果和相关解释表。
开发重点是：结果能不能稳定支撑“后面为什么看这个 SKU”。

## 6. 它不做什么

```text
不直接算价格带
不直接做新品门禁
不直接产最终推荐
```

## 7. 下游谁用

算法 05 会用它来继续看价格带。
算法 06 也会用它来找购物篮里的新品关联。
