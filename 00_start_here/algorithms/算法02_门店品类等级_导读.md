# 算法02_门店品类等级_导读

## 1. 一句话理解

算法 02 做的是：

```text
给每个门店和品类的组合，算出它在当前区域里的经营等级。
```

它先回答“这个场在什么水平”，后面的算法才知道“这个场里的机会怎么看”。

## 2. 它在链路里的位置

算法 02 是门店侧底座。

```text
输入门店和品类经营数据
-> 输出门店品类等级
-> 给算法 03、04、05 提供场景基础
```

## 3. 它读什么

它读门店基础信息、品类映射、区域映射和经营数据。
核心不是看一个单点门店，而是看“门店 + 品类 + 区域”这个组合的稳定水平。

## 4. 它做什么

算法 02 先把门店品类组合放到统一口径里，再根据经营表现分层。
最后输出每个组合的正式等级和支撑结果，让后续算法知道这个场属于什么档位。

## 5. 它产什么

主输出是门店品类等级表，以及配套的参数或解释表。
开发关心的是等级是否按合同粒度落表，是否能稳定复算。

## 6. 它不做什么

```text
不判断消费者画像
不算单个 SKU 的表现
不做新品候选
```

它只管“场”的层级，不管“人”的标签和“货”的机会。

## 7. 下游谁用

下游主要给算法 03、04、05 使用。
后面所有面向目标人群的分析，都需要先知道这个门店品类组合属于什么等级。
