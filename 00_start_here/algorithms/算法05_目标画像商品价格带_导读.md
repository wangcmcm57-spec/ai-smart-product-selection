# 算法05_目标画像商品价格带_导读

## 1. 一句话理解

算法 05 做的是：

```text
把目标画像能接受的价格范围和候选商品的可行价格方案算清楚。
```

它回答的是“这个货在这个场里，价格落在哪更合理”。

## 2. 它在链路里的位置

算法 05 站在锚点和新品候选之间。

```text
04 找到表现好的 SKU
05 看这些货和候选货的价格带
06 再结合购物篮关系看新品机会
```

它是后面成本、售价和毛利可行性判断的底座之一。

## 3. 它读什么

它读算法 04 的锚点结果，再结合价格、成本、毛利和候选相关信息，形成价格带判断。
如果后面有竞品验证，也还是围绕这条价格线去补强。

## 4. 它做什么

算法 05 先给出目标画像层面的可接受价格带。
如果已经有具体候选，再继续补候选售价、成本和毛利可行性。

## 5. 它产什么

主输出是价格带结果、候选价格方案和毛利可行性结果。
开发要看的是：价格带是不是能被后续算法直接拿来用，而不是只停留在口头判断。

## 6. 它不做什么

```text
不重新找消费者画像
不重新找门店等级
不直接做门禁结论
不直接生成最终推荐
```

## 7. 下游谁用

算法 06 会用它判断购物篮机会里的价格是否可行。
算法 08 也会在候选标准化阶段回看这部分价格上下文。
