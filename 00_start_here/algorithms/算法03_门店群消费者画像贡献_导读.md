# 算法03_门店群消费者画像贡献_导读

## 1. 一句话理解

算法 03 做的是：

```text
把会员画像和门店品类等级连起来，看哪类消费者在什么场里贡献最大。
```

它回答的是“谁在这个场里起作用”，是后面选品分析的重要桥梁。

## 2. 它在链路里的位置

算法 03 站在 01 和 02 的中间。

```text
01 给人群标签
02 给场景等级
03 把人群和场景连起来
```

没有 03，后面的目标画像分析会少一层“人群-场景”连接关系。

## 3. 它读什么

它主要读算法 01 的会员画像结果和算法 02 的门店品类等级结果，再结合消费贡献和门店群信息做聚合。

## 4. 它做什么

算法 03 计算不同消费者画像在不同门店群、品类和区域里的贡献度。
如果某类消费者是主力贡献人群，它会在结果里明确标出来。

## 5. 它产什么

主输出是门店群消费者画像贡献表，以及主力画像、贡献得分、贡献占比这类支撑字段。
开发要看的是：这个结果能不能稳定告诉后续算法“主力人群是谁”。

## 6. 它不做什么

```text
不重新算会员画像
不重新算门店等级
不直接找 SKU
不直接产出新品候选
```

## 7. 下游谁用

算法 03 给算法 04、05、06 提供目标画像和场景判断基础。
它是后面“按什么人群看什么货”的起点。
