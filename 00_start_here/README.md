# AI 选品 V1 第一阅读入口

本目录是开发、产品、后端、Agent 和前端第一次进入项目时的导读层。

导读不是归档材料。它负责先讲清“这个项目怎么跑、谁算什么、结果表在哪、AI 在哪里参与”，再让读者按角色下钻到需求、架构、数据合同和算法卡。

## 推荐阅读顺序

1. [项目导读](01_项目导读.md)
2. [端到端链路导读](02_端到端链路导读.md)
3. [算法与结果表总览](03_算法与结果表总览.md)
4. [算法单篇导读](#算法单篇导读)
5. 按角色下钻到 [产品需求](../01_product/README.md)、[架构资料](../02_architecture/README.md)、[数据合同](../03_data_contracts/README.md) 或 [开发版算法卡](../04_algorithm_cards/developer_version/)

## 读法

先抓住三件事：

```text
它读什么
它做什么
它交给谁
```

再看两条边界：

```text
离线算法产表；
在线页面、API 和 Agent 只读结果并解释，不实时重算。
```
